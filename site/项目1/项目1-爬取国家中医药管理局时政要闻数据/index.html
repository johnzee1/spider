    项目1：爬取国家中医药管理局时政要闻数据¶

    合规提示¶

    ⚠️ 在开始本项目的学习之前，请务必阅读以下合规要求：

    1. 仅爬取公开数据：本项目只获取国家中医药管理局官网时政要闻栏目中公开可见的新闻标题、发布时间和详情链接，绝不涉及任何用户隐私或内部数据。
    2. 控制请求频率：本教程所有代码均在两次请求之间使用 time.sleep(2) 间隔至少 2 秒，绝不进行高频访问。
    3. 个人学习用途：项目产出仅供个人学习与技术研究使用，不可用于商业目的或对网站造成负担。
    4. 目标网站为 HTTP 协议：国家中医药管理局网站使用 http://（非加密），这是政府部门网站的常见情况。本教程如实在代码中使用 http://，不代表推荐在生产环境中使用非加密连接。

    爬虫不是"攻击工具"，而是"数据助手"。 请始终保持对目标网站的尊重。

    1.1项目任务与目标¶

    1.1.1 什么是爬虫？（生活化理解）¶

    想象你去图书馆查资料。你的步骤是：

    1. 走到图书馆（发送请求）
    2. 翻看书架上的书（获取网页内容）
    3. 找到你需要的那几段文字，抄到笔记本上（提取有用数据）
    4. 把笔记本带回家（保存数据）

    爬虫做的事情一模一样，只不过"图书馆"变成了"网站"，"抄写"变成了"程序自动提取"。

    用更技术的话说：爬虫 = 用程序自动访问网页，从网页中提取你需要的信息，然后保存下来。

    1.1.2 本项目要做什么？¶

    我们这次的目标非常明确：

    从国家中医药管理局（NATCM）官网的"时政要闻"栏目，自动获取每一条新闻的： - 📌 标题（如"总书记的人民情怀 | '建设社会主义现代化强国，关键在科技自立自强'"） - 📅 发布时间（如 2026-07-07） - 🔗 详情页链接（如 http://www.natcm.gov.cn/xinxifabu/shizhengyaowen/2026-07-07/38302.html）

    然后将这些数据保存到一个 CSV 文件中，方便用 Excel 打开查看。

    1.2.6 写第一段测试代码：测试网络连接¶

    作用说明：在实际爬取数据之前，我们先写一段最简单的代码，测试你的 Python 环境 + requests 库能否正常访问国家中医药管理局网站。这就像出门前先试试门能不能打开。

    📸 操作截图：VS Code 中空白的 spider.py 文件 | 截取范围：整个 VS Code 窗口 | 重点标注：红框圈出右侧空白编辑区域

    请在 spider.py 中写入以下代码：

    # -*- coding: utf-8 -*-
"""
项目1：爬取国家中医药管理局时政要闻数据
第一步：测试网络连接
"""

# ============================================================
# 导入 requests 库
# ============================================================
# requests 是一个"网络通信工具"。
# 它可以帮 Python 程序像浏览器一样，向网站发请求、收数据。
# 它不是你电脑自带的，需要用 pip install requests 安装。
import requests

# ============================================================
# 设置要访问的网址
# ============================================================
# 这是国家中医药管理局的官网首页
# 注意：这个网站使用 http:// 协议（不加密），这是正常现象
url = "http://www.natcm.gov.cn/"

# ============================================================
# 设置请求头（Headers）
# ============================================================
# 请求头就像你进图书馆时出示的学生证。
# 网站看到这些信息后，才知道"哦，这是一个正常的浏览器在访问"。
# User-Agent 是最重要的一个头，告诉网站你是什么浏览器。
# 如果不设置这个，有些网站会直接拒绝你的访问。
headers = {}
headers["User-Agent"] = (
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
    "AppleWebKit/537.36 (KHTML, like Gecko) "
    "Chrome/120.0.0.0 Safari/537.36"
)

# ============================================================
# 开始测试
# ============================================================
print("=" * 50)
print("开始测试网络连接...")
print("=" * 50)

try:
    # --------------------------------------------------------
    # 发送 GET 请求
    # --------------------------------------------------------
    # requests.get() 函数：向指定网址发送一个 GET 请求
    # 参数解释：
    #   第一个参数 url     = 要访问的网址
    #   headers=headers    = 请求头，告诉网站"我是浏览器"
    #   timeout=10         = 最多等待 10 秒，超时就放弃
    # 返回值：一个 Response 对象，包含网站返回的所有信息
    response = requests.get(url, headers=headers, timeout=10)

    # --------------------------------------------------------
    # 查看状态码
    # --------------------------------------------------------
    # status_code 属性：网站返回的 HTTP 状态码
    #   200 = 成功！网站正常返回了内容
    #   404 = 你访问的页面不存在
    #   500 = 网站服务器出了问题
    status_code = response.status_code
    print("✅ 状态码: " + str(status_code))

    # --------------------------------------------------------
    # 查看网页编码
    # --------------------------------------------------------
    # encoding 属性：网页的文字编码方式
    # 中文网站一般是 utf-8 或 gb2312
    page_encoding = response.encoding
    print("📄 网页编码: " + page_encoding)

    # --------------------------------------------------------
    # 查看网页内容（只打印开头 500 个字符）
    # --------------------------------------------------------
    # response.text 属性：网站返回的网页内容（一整个 HTML 字符串）
    # 非常长，所以用 [:500] 只取前 500 个字符看看
    page_content = response.text
    print("📝 网页内容前 500 字符:")
    print(page_content[:500])

    print("=" * 50)
    print("🎉 恭喜！网络连接测试成功！")
    print("=" * 50)

# ------------------------------------------------------------
# 下面的 except 块用来处理"意外情况"
# 就像出门带伞——万一下雨（出错了），不会淋成落汤鸡
# ------------------------------------------------------------

except requests.exceptions.Timeout:
    # 等了 10 秒网站都没反应 → 超时了
    print("❌ 错误：请求超时！请检查网络连接。")
    print("   可能原因：1) 网络不通  2) 网站服务器响应慢  3) 防火墙限制")

except requests.exceptions.ConnectionError:
    # 根本连不上网站 → 网络问题
    print("❌ 错误：连接失败！请确认网址是否正确。")
    print("   可能原因：1) 网址输错了  2) DNS 解析失败  3) 网站不存在")

except Exception as e:
    # 捕获所有其他的意外错误
    # Exception 是所有异常的"父类"，能兜底捕获任何没预料到的错误
    print("❌ 发生了未知错误: " + str(e))

    1.3 理解 HTTP 请求与响应¶

    1.3.1 什么是 HTTP？¶

    作用说明：在正式写爬虫之前，必须先理解浏览器和网站之间是怎么"对话"的。这就像学开车前先要知道油门和刹车在哪。

    生活化理解：

    • 你在浏览器输入网址按回车，相当于你给网站发了一封信，说："请把你这个页面的内容发给我看看"
    • 网站收到信，回了一封信，信里装着网页的内容（HTML 代码）
    • 这在技术上叫 HTTP 请求（Request） 和 HTTP 响应（Response）

    1.3.2 用浏览器开发者工具查看请求和响应¶

    作用说明：每个浏览器都自带"开发者工具"，可以让你看到请求和响应的详细内容。写爬虫的核心能力之一，就是会用它来分析目标网站。

    操作步骤（以 Chrome 浏览器为例，Edge 操作完全一致）：

    1. 打开 Chrome 浏览器
    2. 在地址栏输入 http://www.natcm.gov.cn/xinxifabu/shizhengyaowen/，按回车
    3. 页面加载完毕后，按下键盘上的 F12 键（位于键盘最上面一排，Esc 键的右边）
    4. 浏览器右侧或底部会弹出一个面板，这就是"开发者工具"
    5. 在开发者工具顶部，点击 "Network"（网络） 标签页
    6. 此时你可能看到一片空白。别急，按一下键盘的 F5 刷新页面，Network 面板就会开始记录所有请求
    7. 在 Network 面板的列表中，找到第一个请求条目，点击它
    8. 右侧会显示这个请求的详细信息

    1.3.3 看懂请求头（Request Headers）¶

    在开发者工具右侧面板中，找到 "Request Headers"（请求头） 部分。

    请求头字段 含义（通俗解释） 你在爬虫中要不要设置？
    User-Agent 告诉网站"我是什么浏览器"。就像你进图书馆时亮出学生证 ✅ 必设，否则容易被拒绝
    Accept 告诉网站"我能接收什么格式的内容" ⭕ 可选
    Accept-Language 告诉网站"我偏好什么语言" ⭕ 可选
    Cookie 你的"身份标识"，用于登录状态等 ⭕ 爬公开数据一般不需要
    Referer 告诉网站"我是从哪个页面跳转过来的" ⭕ 可选

    1.3.4 GET 和 POST 的区别¶

    作用说明：HTTP 请求主要有两种类型——GET 和 POST。理解它们的区别，是写爬虫的基本功。

    生活化理解：

    对比维度 GET 请求 POST 请求
    比喻 去图书馆借书看 去图书馆填表提交资料
    数据位置 数据在网址上（?key=value） 数据在请求"身体"里（不可见）
    用途 获取信息（查新闻、看公告） 提交信息（登录、搜索、评论）
    可见性 参数在网址栏可见 参数网址栏看不到
    我们的项目 ✅ 主要使用 GET，获取新闻列表 如果网站有搜索框，搜索时用 POST

    1.3.5 看懂响应（Response）¶

    在开发者工具右侧面板中，点击 "Response"（响应） 标签页，你会看到网站返回给你的内容——一大段 HTML 代码。

    你需要关注三个关键信息：

    信息 在哪里看 含义
    状态码 Headers 标签页最顶部 200=成功，404=找不到，500=服务器错误
    编码 Headers → Content-Type utf-8 或 gb2312，决定怎么解码中文
    网页内容 Response 标签页 就是我们之后要用正则表达式提取数据的"原材料"

    1.3.6 实战：用 requests.get() 获取时政要闻页面¶

    作用说明：现在我们要把刚才在浏览器里看到的东西，用 Python 代码"拿"过来。

    将 spider.py 中的代码替换为以下内容：

    # -*- coding: utf-8 -*-
"""
项目1：爬取国家中医药管理局时政要闻数据
第二步：获取时政要闻页面的源码
"""
import requests

# ============================================================
# 1. 准备工作：设置请求头，伪装成浏览器
# ============================================================
headers = {}
headers["User-Agent"] = (
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
    "AppleWebKit/537.36 (KHTML, like Gecko) "
    "Chrome/120.0.0.0 Safari/537.36"
)
headers["Accept"] = "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8"

# 目标网址：国家中医药管理局"时政要闻"栏目
url = "http://www.natcm.gov.cn/xinxifabu/shizhengyaowen/"

# ============================================================
# 2. 发送 GET 请求
# ============================================================
print(">>> 正在访问国家中医药管理局时政要闻栏目...")
print(">>> 目标网址: " + url)
print()

try:
    # 发送 GET 请求，timeout=15 表示最多等 15 秒
    response = requests.get(url, headers=headers, timeout=15)

    1.4 正则表达式提取数据¶

    作用说明：现在我们已经拿到了网页的 HTML 源码，接下来需要从中"捞"出有用的信息——新闻标题、发布时间、详情链接。这就要用到正则表达式，它是文本处理的"瑞士军刀"。

    1.4.1 什么是正则表达式？（生活化理解）¶

    想象你在一个装满杂物的抽屉（网页源码）里找东西：

    • 找所有手机号（11 位数字）→ 你需要一个"匹配 11 位数字"的规则
    • 找所有邮箱地址（xxx@xxx.com）→ 你需要一个"匹配邮箱格式"的规则
    • 找所有日期（2026-07-07）→ 你需要一个"匹配 YYYY-MM-DD 格式"的规则

    正则表达式就是用来描述这些"匹配规则"的语言。

    1.4.2 正则基础：你需要记住的核心语法¶

    作用说明：不需要学全部正则语法，本项目只用以下核心语法就够。

    正则符号 含义 示例 能匹配什么？
    . 匹配任意一个字符（除了换行） a.c abc、a1c、a c
    * 前面的东西出现 0 次或多次 ab*c ac、abc、abbc
    + 前面的东西出现 1 次或多次 ab+c abc、abbc（不匹配 ac）
    ? 前面的东西出现 0 次或 1 次 ab?c ac、abc
    () 分组，把匹配的内容"抓"出来 (\d+)-(\d+) 捕获年、月两组数字
    .*? 非贪婪匹配（最短匹配） <a>(.*?)</a> 匹配最短的 <a> 标签内容
    \d 匹配一个数字（0-9） \d{3} 123、456
    \w 匹配一个字母/数字/下划线 \w+ hello、abc123
    \s 匹配一个空白字符（空格、换行等） a\sb a b
    [^x] 匹配不是 x 的任意字符 [^"]+ 匹配"非双引号"的任意字符

    最关键的区别 —— 贪婪 vs 非贪婪：

    这是新手最容易踩的坑。假设有这样一段 HTML：

    <a href="1.html">新闻A</a>  <a href="2.html">新闻B</a>
    正则 匹配结果 解释
    <a href="(.*)"> 1.html">新闻A</a> <a href="2.html ❌ 贪婪：一路吃到最后一个 ">
    <a href="(.*?)"> 1.html（第一个）、2.html（第二个） ✅ 非贪婪：遇到第一个 "> 就停

    🔑 记住：写爬虫时，除非你就是想要匹配全部内容，否则一律用 .*? 而不要用 .*！

    1.4.3 Python 中使用正则表达式¶

    作用说明：Python 通过 re 模块（内置，不需要安装）来使用正则。

    三个最常用的函数：

    1.4.5 逐步写出正则表达式¶

    作用说明：现在根据上面分析的结构，一步步写出正则表达式。注意：我们不写一个"超级正则"，而是每一步只匹配一个字段，拆开写更容易理解和调试。

    第一步：找到所有 a 标签和日期组合

    每条新闻的核心 HTML 片段是这样的：

    <a href="链接" title="标题">标题</a> <span>日期</span>

    我们先写一个简单的正则，把页面上所有的 <a> 标签都找出来。

    # 匹配一个完整的 a 标签（从 <a 开始到 </a> 结束）
# 注意：用 .*? 而不是 .*，因为我们要最短匹配
a_tag_pattern = r'<a[^>]*>.*?</a>'

    第二步：从每个 a 标签中提取链接（href）

    # href 的值在双引号中
# [^"] 表示"任何不是双引号的字符"
# [^"]+ 表示"一个或多个非双引号的字符"（就是链接本身）
# 括号 () 表示"把这一部分捕获出来，我后面要用"
href_pattern = r'href="([^"]+)"'

    第三步：从每个 a 标签中提取标题（title）

    # title 的值也在双引号中，写法跟 href 一样
title_pattern = r'title="([^"]+)"'

    第四步：从 a 标签后面的 span 标签中提取日期

    # 日期格式固定为 YYYY-MM-DD
# \\d 表示任意数字（0-9）
# \\d{4} 表示正好 4 个数字（年份）
# \\d{2} 表示正好 2 个数字（月份/日期）
date_pattern = r'<span[^>]*>(\\d{4}-\\d{2}-\\d{2})</span>'

    把这四步串起来的过程：

    1. 从整页 HTML 中，找到每条 <a>...</a> <span>...</span> 组合
    2. 对每一条，用三个小正则分别提取：链接、标题、日期
    3. 每个字段独立提取，清晰易懂

import requests
import re
import csv
import time


def fetch_page(url):
    """
    发送 GET 请求，获取网页 HTML 源码

    参数:
        url: 目标网址（字符串）
    返回:
        HTML 源码字符串，失败时返回 None
    """
    # 设置请求头 —— 告诉网站"我是浏览器"
    headers = {}
    headers["User-Agent"] = (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/120.0.0.0 Safari/537.36"
    )
    headers["Accept"] = "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8"

    try:
        print("[请求] 正在访问: " + url)

        # 发送 GET 请求
        # timeout=15 表示最多等 15 秒
        response = requests.get(url, headers=headers, timeout=15)
        #网站源码转码，一般都是utf-8编码

        response.encoding = 'utf-8'
        status_code = response.status_code
        print("[请求] HTTP 状态码: " + str(status_code))

        # 只有状态码 200 才表示成功
        if status_code == 200:
            return response.text
        else:
            print("[警告] 状态码异常 (" + str(status_code) + ")，请检查目标网址")
            return None

    except requests.exceptions.Timeout:
        # 等了 15 秒还没响应 → 超时
        print("[错误] 请求超时！网站响应太慢或网络不通。")
        return None
    except requests.exceptions.ConnectionError:
        # 根本连不上 → 网络问题
        print("[错误] 连接失败！请检查网络连接。")
        return None


def parse_news(html):
    """
    从 HTML 源码中提取新闻信息

    参数:
        html: 网页 HTML 源码（字符串）
    返回:
        新闻记录列表，每项是 {"标题": str, "发布时间": str, "链接": str}
    """
    # --------------------------------------------------------
    # 步骤 1：找到所有 li 标签块
    # --------------------------------------------------------
    # 每条新闻在一个 <li>...</li> 标签内
    # re.compile() 把正则编译成规则对象，可以重复使用
    # re.DOTALL 让 . 也能匹配换行符（HTML 标签通常跨多行）
    li_pattern = re.compile(r'<li>(.*?)</li>', re.DOTALL)

    # findall() 返回所有匹配的片段，是一个列表
    all_li_blocks = li_pattern.findall(html)
    print("[解析] 找到 " + str(len(all_li_blocks)) + " 个 li 标签块")

    # --------------------------------------------------------
    # 步骤 2：准备四个小正则，分别提取不同字段
    # --------------------------------------------------------
    # 注意：不写一个"超级正则"一次性匹配所有字段
    # 而是每个字段独立提取，更清楚、更容易调试
    #
    # 正则1：提取 href 属性中的链接
    #   [^"]+ = 一个或多个非双引号的字符（就是链接本身）
    #   括号 () = 把匹配到的内容"捕获"出来
    href_pattern = re.compile(r'href="([^"]+)"')

    # 正则2：提取 title 属性中的标题
    title_pattern = re.compile(r'title="([^"]+)"')

    # 正则3：备用方案——如果 a 标签没有 title 属性，
    #   提取 a 标签内部的文字作为标题
    inner_text_pattern = re.compile(r'<a[^>]*>([^<]+)</a>')

    # 正则4：提取 YYYY-MM-DD 格式的日期
    #   \d = 任意数字(0-9)
    #   \d{4} = 正好4个数字
    #   \d{2} = 正好2个数字
    date_pattern = re.compile(r'(\d{4}-\d{2}-\d{2})')

    # --------------------------------------------------------
    # 步骤 3：逐条处理每个 li 块
    # --------------------------------------------------------
    news_list = []

    for li_block in all_li_blocks:

        # ----- 3-1 提取链接 -----
        # search()：在文字中找第一个匹配的位置
        # 如果找到了返回 Match 对象，没找到返回 None
        link_match = href_pattern.search(li_block)
        if link_match is not None:
            # group(1)：取出第一个括号 () 捕获的内容
            href = link_match.group(1)
        else:
            href = ""

        # ----- 3-2 提取标题 -----
        # 优先用 title 属性（通常更完整、不截断）
        title_match = title_pattern.search(li_block)
        if title_match is not None:
            title = title_match.group(1)
        else:
            # 备用：用 a 标签内部的文字
            inner_match = inner_text_pattern.search(li_block)
            if inner_match is not None:
                title = inner_match.group(1)
            else:
                title = ""

        # ----- 3-3 清洗标题 -----
        # .strip()：去掉字符串两端的空白（空格、换行等）
        title = title.strip()
        # re.sub()：把匹配正则的部分替换掉
        #   \s+ = 一个或多个空白字符
        #   替换成一个普通空格 ' '
        title = re.sub(r'\s+', ' ', title)

        # ----- 3-4 提取日期 -----
        date_match = date_pattern.search(li_block)
        if date_match is not None:
            date = date_match.group(1)
            date = date.strip()
        else:
            date = ""

        # ----- 3-5 处理链接：相对路径 → 完整 URL -----
        # 网页里的链接是 /xinxifabu/.../38302.html
        # 需要补上域名变成完整网址
        # startswith('/')：判断字符串是否以 '/' 开头
        if href.startswith('/'):
            full_link = "http://www.natcm.gov.cn" + href
        else:
            full_link = href

        # ----- 3-6 筛选有效记录 -----
        # 只有三个字段都非空（有内容）才存入列表
        if title != "" and full_link != "" and date != "":
            # 创建字典，存一条新闻的三个字段
            item = {}
            item["标题"] = title
            item["发布时间"] = date
            item["链接"] = full_link
            news_list.append(item)

    print("[解析] 有效记录: " + str(len(news_list)) + " 条")
    return news_list

    1.6.1 问题一：ModuleNotFoundError: No module named 'requests'¶

    错误现象：

    ModuleNotFoundError: No module named 'requests'

    原因：Python 环境中还没有安装 requests 库。

    3. 看到 Successfully installed 即可
    4. 重新运行 spider.py

    1.6.2 问题二：状态码不是 200¶

    状态码 含义 解决办法
    404 页面不存在 检查 URL 是否正确，浏览器手动打开试试
    500 服务器错误 等几分钟再运行
    403 禁止访问 检查 User-Agent 是否正确设置

    1.6.3 问题三：正则匹配为空（提取到 0 条）¶

    原因：网站 HTML 结构改版了。

    排查三步走：

    1. 打开 page_source.html，搜索新闻标题关键词，确认 HTML 结构是否变了
    2. F12 → Elements 面板重新分析一条新闻的 HTML
    3. 修改正则表达式匹配新的结构

    1.6.4 重要提醒：不要频繁请求！¶

    ⚠️ 如果短时间内发送大量请求，会给网站服务器造成负担。

    本代码已内置保护：

    • ✅ 两次 time.sleep(2)：请求间隔至少 2 秒
    • ✅ timeout=15：超时就放弃
    • ✅ 只访问列表页

    如果你要爬多页，务必遵守：

    page_num = 1
