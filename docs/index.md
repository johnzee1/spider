# Python爬虫实战教程 — 医疗公开数据

欢迎！这是一套为零基础大专学生编写的 **Python 爬虫实战教程**，共 6 个项目，涵盖从基础到进阶的完整爬虫技术栈。

## 课程特色

- 全程基于**真实公开的医疗健康网站**
- 从 `requests` 到 `Selenium` 到 `Scrapy`，循序渐进
- 每行代码都有详细注释，零基础也能看懂
- 配合作业练习，边学边练

## 项目列表

| 项目 | 标题 | 核心技术 |
|------|------|---------|
| 项目1 | 爬取国家中医药管理局时政要闻数据 | requests + BeautifulSoup |
| 项目2 | 爬取医疗健康资讯网站数据 | requests + 分页爬取 |
| 项目3 | XPath爬取医学百科药品数据 | lxml + XPath |
| 项目4 | 爬取医学百科网站数据 | requests + 多页面爬取 |
| 项目5 | Scrapy入门指导书 | Scrapy 框架 |
| 项目6 | Selenium动态爬虫实战 | Selenium + ChromeDriver |

## 环境要求

- Python 3.8 或更高版本
- VS Code（编程环境）
- 需要安装的库在各项目中单独说明

## 使用方法

从左侧导航栏选择项目，按顺序学习即可。建议从项目1开始，不要跳课。
