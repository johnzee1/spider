# 项目4：爬取医学百科网站数据

这一章练习“多页采集”。不要一开始就写复杂的自动翻页：先把需要采集的公开页面地址放进列表，逐页处理，程序会更容易读懂和排错。

> 医学百科页面是公开资料，不等于专业诊疗建议。只采集少量公开页面，并为每次请求留出间隔。

## 本章任务

依次访问多个页面，取出页面标题和部分链接，合并保存为一个 CSV 文件。

## 先理解“多页”

```python
PAGE_URLS = [
    "第 1 页的地址",
    "第 2 页的地址",
    "第 3 页的地址",
]

for url in PAGE_URLS:
    # 每次循环只处理一页
    pass
```

先用浏览器打开需要的页面，把地址复制进 `PAGE_URLS`。当这份简单代码能跑通后，再学习自动寻找“下一页”链接。

## 完整代码

保存为 `multi_page_spider.py`，或下载本章的[完整代码](multi_page_spider.py)。这里的两个地址只是示例，可换成你在浏览器中确认过的公开页面。

```python
import csv
import time
from urllib.parse import urljoin

import requests
from bs4 import BeautifulSoup

PAGE_URLS = [
    "https://www.a-hospital.com/w/%E9%9D%92%E9%9C%89%E7%B4%A0",
    "https://www.a-hospital.com/w/%E9%98%BF%E8%8E%AB%E8%A5%BF%E6%9E%97",
]
HEADERS = {"User-Agent": "Mozilla/5.0"}


def get_one_page(url):
    response = requests.get(url, headers=HEADERS, timeout=15)
    response.raise_for_status()
    return BeautifulSoup(response.text, "html.parser")


def parse_links(soup, page_url):
    rows = []
    for link in soup.select("a[href]"):
        name = link.get_text(" ", strip=True)
        if len(name) >= 2:
            rows.append({"来源页面": page_url, "名称": name,
                         "链接": urljoin(page_url, link["href"])})
    return rows[:15]


def main():
    all_rows = []
    for number, url in enumerate(PAGE_URLS, start=1):
        print(f"正在处理第 {number} 页：{url}")
        all_rows.extend(parse_links(get_one_page(url), url))
        time.sleep(1)

    with open("medicine_pages.csv", "w", newline="", encoding="utf-8-sig") as file:
        writer = csv.DictWriter(file, fieldnames=["来源页面", "名称", "链接"])
        writer.writeheader()
        writer.writerows(all_rows)
    print(f"保存完成，共 {len(all_rows)} 条")


if __name__ == "__main__":
    main()
```

`time.sleep(1)` 是每处理一页停 1 秒。它不是为了让程序变慢，而是避免短时间连续访问网站。

## 常见问题

| 现象 | 处理 |
|---|---|
| 第二页打不开 | 先复制该地址到浏览器确认，再替换 `PAGE_URLS` |
| 数据重复 | 使用 `set()` 记录已经出现过的链接，再决定是否追加 |
| 请求太快 | 把 `time.sleep(1)` 改为 `time.sleep(2)` |
