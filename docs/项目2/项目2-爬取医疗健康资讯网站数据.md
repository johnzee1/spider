## 2.1 项目任务 —— 为什么需要 BeautifulSoup？

### 本节目标

- 理解为什么正则表达式不够用了
- 认识 HTML 的树形结构
- 明确本项目要做什么

### 从项目1说起 —— 正则的"天花板"

在项目1中，我们用正则表达式提取了新闻标题和日期。那种写法在面对**简单、规整、数据量少**的页面时够用。

但如果需求变成这样：爬取一个医疗资讯网站首页的 **标题 + 作者 + 时间 + 摘要 + 标签**，共 5 个字段，每个出现在不同的 HTML 标签里。用正则写，需要 5 种不同的匹配规则，只要网站改一个 class 名，全部得重写。

正则的局限在于：它只能做**文本匹配**，不知道 HTML 的**结构关系**。

### BeautifulSoup 是什么？（煮汤圆比喻）

把 HTML 想象成一碗**黑芝麻汤圆**：

- 汤圆皮 = `<div>`、`<li>`、`<a>` 这些 HTML **标签**
- 黑芝麻馅 = 标签里面的**内容**（标题、日期这些文字）
- 汤圆皮上的贴纸 = `class="list_title"`、`id="main"` 这些**属性**

**正则**的做法：把所有汤圆搅碎了，从一堆碎屑里翻黑芝麻。费劲，还容易弄丢。

**BeautifulSoup** 的做法：**不吃汤圆，只找标签**。它把整碗汤圆端过来，一颗一颗看贴纸，把需要的挑出来。

```python
# 对比两种写法：
# 正则方式（项目1）
import re
href_pattern = re.compile(r'href="([^"]+)"')
title_pattern = re.compile(r'title="([^"]+)"')

# BeautifulSoup 方式（本项目）
from bs4 import BeautifulSoup
soup = BeautifulSoup(html, "lxml")
# 按 class 名找 —— 不需要写匹配规则
titles = soup.find_all("div", class_="list_title")
```

### HTML 的树形结构（家族比喻）

一个网页的 HTML 其实是一棵**家族树**：

```html
<div class="list_box">                 ← 爷爷
    <a class="list_line">              ← 爸爸
        <div class="list_pic">...</div>  ← 孙子
        <div class="list_flex">          ← 孙子
            <div class="list_title">新闻标题</div>   ← 曾孙
            <div class="list_text">摘要</div>        ← 曾孙
            <div class="list_time">2026-07-10</div>  ← 曾孙
        </div>
    </a>
</div>
```

- `list_box` 是 `list_line` 的**父节点**（parent）
- `list_title` 和 `list_text` 是**兄弟节点**（有同一个爸爸）
- `list_title` 是 `list_box` 的**子孙节点**（可以隔代）

BS4 的核心价值：**沿着这棵家族树，找到任何想要的信息。**

print("=" * 60)
print()
print("✅ BeautifulSoup 装载成功！")

### 2.3.2 find_all() —— 一次性找到所有新闻

> 生活比喻：`find_all()` = 在一碗汤圆里，把所有贴着某种标签的全部挑出来。

**语法：**

```python
soup.find_all("标签名", class_="类名")
#   参数1: HTML 标签名（"div", "a", "span" 等）
#   参数2: class_  类名（注意有下划线！因为 class 是 Python 关键字）
#   返回值: 列表，包含所有匹配的元素
```

**代码实现：**

```python
# -*- coding: utf-8 -*-
"""
项目2：爬取医疗健康资讯网站数据
第2.3节：find() 和 find_all() 提取新闻数据
"""
import requests
from bs4 import BeautifulSoup

# 获取网页
headers = {}
headers["User-Agent"] = (
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
    "AppleWebKit/537.36 (KHTML, like Gecko) "
    "Chrome/120.0.0.0 Safari/537.36"
)
url = "https://news.medlive.cn/"
response = requests.get(url, headers=headers, timeout=15)
html = response.text
soup = BeautifulSoup(html, "lxml")

# ============================================================
# 步骤 1：用 find_all() 找到所有新闻条目
# ============================================================
# "a.list_line" 不写也可以，就这么写：
#   soup.find_all("a", class_="list_line")
#   参数 "a"         = 找 a 标签
#   参数 class_="list_line" = 要求 class 必须是 list_line
all_news = soup.find_all("a", class_="list_line")

news_count = len(all_news)
print(">>> 找到 " + str(news_count) + " 条新闻")
print()

# ============================================================
# 步骤 2：遍历每条新闻，用 find() 提取字段
# ============================================================
show_count = 3  # 只展示前 3 条（避免刷屏）
if news_count < 3:
    show_count = news_count

for i in range(show_count):
    # 取第 i 条新闻
    news_item = all_news[i]

    # ----- 提取链接 -----
    # .get("属性名") 方法：取标签的某个属性的值
    # 比如 <a href="/xxx"> → .get("href") 返回 "/xxx"
    # 第二个参数 "" = 如果没这个属性，返回空字符串（而不是报错）
    link = news_item.get("href", "")

    # 如果链接是相对路径（以 / 开头），在前面补上域名
    if link.startswith("/"):
        link = "https://news.medlive.cn" + link

    # ----- 提取标题 -----
    # .find("标签", class_="类名") = 在当前元素内部，找第一个匹配的子元素
    # 返回值：找到了返回 Tag 对象，没找到返回 None
    title_tag = news_item.find("div", class_="list_title")
    if title_tag is not None:
        # .get_text() 方法：取标签内部的纯文本
        # strip=True：去掉首尾的空白（空格、换行等）
        title = title_tag.get_text(strip=True)
    else:
        title = "未找到标题"

    # ----- 提取摘要 -----
    text_tag = news_item.find("div", class_="list_text")
    if text_tag is not None:
        summary = text_tag.get_text(strip=True)
    else:
        summary = "暂无摘要"

    # ----- 提取日期 -----
    time_tag = news_item.find("div", class_="list_time")
    if time_tag is not None:
        date = time_tag.get_text(strip=True)
    else:
        date = "未找到日期"

    # ----- 打印 -----
    print("第 " + str(i + 1) + " 条：")
    print("  标题: " + title)
    print("  摘要: " + summary)
    print("  日期: " + date)
    print("  链接: " + link)
    print()

print("=" * 60)
print("✅ 共找到 " + str(news_count) + " 条新闻记录")
print("=" * 60)
```

### 2.3.3 find() 和 find_all() 的区别

|  | find_all() | find() |
|------|-----------|--------|
| 找多少个？ | 所有匹配的 | 第一个匹配的 |
| 返回类型 | **列表**（即使是空也是空列表） | **单个元素**（找到→Tag，没找到→None） |
| 什么时候用？ | 页面上有多个同类元素时（如10条新闻） | 确认只有一个时（如每条新闻里只有一个标题div） |

**记忆口诀：**

- `find_all` = 端走一整碗（拿回来一个列表，能数有几个）
- `find` = 夹起一颗（直接拿到手，或者没有）

### 2.3.4 常见坑点

**坑1：`class_` 的下划线不能忘**

```python
# ❌ 错误！class 是 Python 关键字
soup.find_all("div", class="list_title")

# ✅ 正确！BS4 规定加下划线
soup.find_all("div", class_="list_title")
```

**坑2：find_all() 返回的是列表，不能直接 .find()**

```python
# ❌ 错误！列表没有 .find() 方法
all_news = soup.find_all("a", class_="list_line")
title = all_news.find("div", class_="list_title")  # 报错！

# ✅ 正确！先取列表某一条，再 find
first_news = all_news[0]
title = first_news.find("div", class_="list_title")  # 正确！
```

**坑3：元素可能不存在，先判断再使用**

```python
# 永远先判断是否找到了！
time_tag = news_item.find("div", class_="list_time")
if time_tag is not None:
    date = time_tag.get_text(strip=True)
else:
    date = "未找到日期"  # 给默认值，程序不崩
```

### 2.4.2 children —— 只看"亲儿子"

> 生活比喻：爷爷有三个儿子，`children` 只列出这三个亲儿子，不管孙子辈的事。

```python
# ============================================================
# children 属性：获取"直接子节点"
# ============================================================
# 注意：children 返回的是迭代器（可理解为一种特殊列表）
# 并且它会包含"换行符和空格"（NavigableString 类型）
# 所以我们用 child.name is not None 过滤，只看 Tag 类型

print("=" * 60)
print(">>> children：只列出直接子节点")
print("=" * 60)

child_count = 0
for child in flex_div.children:
    # .name 属性：Tag 对象有名称（如 "div"），文字节点是 None
    if child.name is not None:
        child_count = child_count + 1
        child_class = child.get("class", "")
        print("  子节点 #" + str(child_count))
        print("    标签: <" + child.name + ">")
        print("    class: " + str(child_class))
        # 只显示前 50 个字符
        text = child.get_text(strip=True)
        print("    内容: " + text[:50])
        print()

print(">>> children 中的 Tag 总数: " + str(child_count))
```

### 2.4.3 descendants —— 看"全部后代"

> 生活比喻：`descendants` 把家族从头到尾撸一遍——儿子、孙子、曾孙，一个不落。

```python
# ============================================================
# descendants 属性：递归获取所有后代（不限层级）
# ============================================================

print("=" * 60)
print(">>> descendants：所有后代节点（只显示前 10 个 Tag）")
print("=" * 60)

desc_count = 0
for desc in flex_div.descendants:
    if desc.name is not None:
        desc_count = desc_count + 1
        if desc_count <= 10:
            desc_class = desc.get("class", "")
            text = desc.get_text(strip=True)
            print("  #" + str(desc_count) + " <" + desc.name + "> class=" + str(desc_class) + " → " + text[:40])

print()
print(">>> descendants 中的 Tag 总数: " + str(desc_count))
```

### 2.4.4 children 和 descendants 的关键区别

```html
<div class="list_flex">           ← 参考节点
    <div class="list_title">      ← 子节点（children 能看到）
        标题文字                   ← 孙子（只有 descendants 能看到）
    </div>
    <div class="list_text">       ← 子节点
        摘要文字                   ← 孙子
    </div>
</div>
```

| 方法 | 能看到谁？ | 实际用途 |
|------|----------|---------|
| `.children` | 只有 list_title 和 list_text 两个 div | 遍历一篇文章的元信息（标题、作者、时间） |
| `.descendants` | 上面的两个 div **加上**它们内部的文字（标题文字、摘要文字） | 递归查找所有含某关键词的文本 |

### 2.4.5 next_sibling —— 找下一个兄弟

> 生活比喻：在聚会上找**右边坐的谁**。

```python
# ============================================================
# next_sibling：从标题出发，一路找到摘要和日期
# ============================================================

title_tag = flex_div.find("div", class_="list_title")
if title_tag is not None:
    print(">>> 当前位置（标题）: " + title_tag.get_text(strip=True)[:40])

    # 找下一个兄弟
    # 注意！HTML 中标签之间的换行/空格也是"兄弟"（NavigableString）
    # 所以可能要跨过好几个空节点才能到真正的下一个 Tag
    current = title_tag.next_sibling

    # 跳过那些不是 Tag 的"假兄弟"（换行符、空白）
    step = 0
    while current is not None and current.name is None and step < 10:
        current = current.next_sibling
        step = step + 1

    if current is not None and current.name is not None:
        print(">>> 下一个兄弟（摘要）: " + current.get_text(strip=True)[:40])

        # 再找下一个兄弟（日期）
        current = current.next_sibling
        step = 0
        while current is not None and current.name is None and step < 10:
            current = current.next_sibling
            step = step + 1

        if current is not None and current.name is not None:
            print(">>> 再下一个兄弟（日期）: " + current.get_text(strip=True))

print()
```

### 2.4.6 parent —— 向上找父节点

> 生活比喻：只知道"我是标题"，但想知道"我在哪条新闻里、哪个栏里"，一层层往上找。

```python
# ============================================================
# parent 属性：向上查找父节点链
# ============================================================

print(">>> 向上查找（从标题一直找到 body）：")
current_node = flex_div  # 从 list_flex 开始
level = 0

while current_node is not None and level < 8:
    level = level + 1
    node_name = current_node.name
    node_class = str(current_node.get("class", "无class"))

    # 找父节点
    parent_node = current_node.parent
    if parent_node is not None:
        parent_name = parent_node.name
    else:
        parent_name = "无"

    print("  " + str(level) + ". <" + node_name + "> class=" + node_class)
    print("     ↑ 父节点是 <" + parent_name + ">")

    # 继续向上
    current_node = parent_node
```

## 2.5 CSS 选择器 —— 更简洁的查找方式

### 本节目标

- 理解什么是 CSS 选择器
- 用 `select()` 替代 `find_all()`，用 `select_one()` 替代 `find()`
- 掌握 5 种最常用的选择器语法

### 2.5.1 什么是 CSS 选择器

CSS 选择器是网页排版中用来"选中元素"的语法。因为所有网页都用 CSS 写样式，所以 BS4 也支持用 CSS 选择器来找元素。

**一句话：用更少的代码，描述"我要找什么"。**

### 2.5.2 5 种最常用选择器

| 选择器 | 含义 | 示例 | 匹配什么？ |
|------|------|------|-----------|
| `标签名` | 按 HTML 标签 | `div` | 所有 `<div>` |
| `.类名` | 按 class | `.list_title` | 所有 `class="list_title"` |
| `父 > 子` | 直接子元素 | `.flex > div` | `.flex` 的**直接**子 div |
| `祖先 后代` | 任意后代 | `.box .title` | `.box` 内部任意层级的 `.title` |
| `[attr*=val]` | 属性包含 | `[href*="show-"]` | href 包含 "show-" 的链接 |

### 2.5.3 代码对比：find_all() vs select()

```python
# -*- coding: utf-8 -*-
"""
项目2 第2.5节：CSS 选择器演示
"""

# === 旧写法：find_all() + find() ===
all_news = soup.find_all("a", class_="list_line")
for item in all_news:
    title_tag = item.find("div", class_="list_title")
    time_tag = item.find("div", class_="list_time")
    # ... 后续处理 ...

# === 新写法：select() + select_one() ===
# select() = find_all 的 CSS 版本
# 参数：CSS 选择器字符串
# 返回值：列表（和 find_all 一样）
all_news = soup.select("a.list_line")
#   "a.list_line" = class 叫 list_line 的 a 标签
#   就像你在 CSS 里写 a.list_line { color: red; }

for item in all_news:
    # select_one() = find 的 CSS 版本
    # 返回单个元素，没找到返回 None
    title_tag = item.select_one("div.list_title")
    time_tag = item.select_one("div.list_time")
    # ... 后续处理和 find 版本完全一样 ...
```

### 2.5.4 更多选择器示例

```python
# ---------- 按标签名 ----------
all_links = soup.select("a")
print("页面上 a 标签总数: " + str(len(all_links)))

# ---------- 按类名 ----------
all_titles = soup.select(".list_title")
print("标题总数: " + str(len(all_titles)))

# ---------- 组合：祖先 + 后代 ----------
# .list_box 下面的所有 .list_title（不管隔多少层）
titles = soup.select(".list_box .list_title")
print("list_box 内的标题: " + str(len(titles)))

# ---------- 直接子元素 ----------
# 只找 .list_flex 的"直接"子 div
direct = soup.select(".list_flex > div")
print("list_flex 的直接子 div: " + str(len(direct)))

# ---------- 属性包含 ----------
# href 属性中包含 "show-" 的链接
show_links = soup.select('a[href*="show-"]')
print("含 show- 的链接: " + str(len(show_links)))

# ---------- 只取前 N 条 ----------
# limit 参数：最多返回几条
first_three = soup.select(".list_title", limit=3)
print("前3条标题:")
for t in first_three:
    print("  - " + t.get_text(strip=True)[:50])
```

### 2.5.5 速查表

| 任务 | find_all 写法 | select 写法 |
|------|-------------|------------|
| 找所有 class=A 的 div | `soup.find_all("div", class_="A")` | `soup.select("div.A")` |
| 找第一个 class=A 的 div | `soup.find("div", class_="A")` | `soup.select_one("div.A")` |
| 在子元素中继续找 | `.find("div", class_="B")` | `.select_one("div.B")` |
| 按多条件找 | 写复杂 attrs 参数 | `select('[href*="show-"][target="_blank"]')` |

> 推荐在项目中使用 `select_one()` 和 `select()`：代码更短、和网页开发者共享同一套语法。

### 2.5.6 调试建议

> `select()` 返回空列表 ≠ 代码写错，可能是 CSS 选择器语法笔误。用 F12 → Elements → Ctrl+F → 把你写的选择器粘贴进搜索框，看浏览器能不能高亮到目标元素。浏览器能搜到，BS4 就能找到。

## 2.6 完整实战：翻页爬取 + JSON 存储

### 本节目标

- **切换到人民网健康**，演示完整的翻页爬取流程
- 用 `select()` 提取滚动新闻列表
- 实现翻页终止条件（翻到没有"下一页"时停止）
- 数据存入 JSON 文件
- 完整的异常处理

### 2.6.1 分析人民网健康的翻页结构

人民网健康滚动新闻页面：`https://health.people.com.cn/GB/415859/index.html`

翻页区域的 HTML 结构：

```html
<div class="page_n clearfix">
    <a class="common_current_page">1</a>     ← 当前页
    <a href="index2.html">2</a>              ← 第2页
    <a href="index3.html">3</a>              ← 第3页
    ...
    <a href="index2.html">下一页</a>          ← 注意！文字是"下一页"而非单独的类名
</div>
```

**翻页策略：**

1. 先构造第 1 页 URL：`https://health.people.com.cn/GB/415859/index.html`
2. 每爬完一页，找"下一页"链接
3. 如果"下一页"的 text 是 "下一页" 且 href 存在 → 继续翻
4. 如果不存在 → 停止

### 2.6.2 新闻条目结构

每条新闻大致是这样的 HTML（不同新闻可能略有差异）：

```html
<li>
    <a href="https://health.people.com.cn/n1/2026/0710/c14739-40757267.html">
        新闻标题
    </a>
    2026-07-10
</li>
```

我们的提取策略：
1. 用 `select()` 找所有列表中的 `<a>` 标签（包含 `n1/` 路径的）
2. 相邻提取日期



### 2.6.3 完整源码

```python
# -*- coding: utf-8 -*-

"""

项目2：爬取医疗健康资讯网站数据

第2.6节：完整实战 —— 翻页爬取 + JSON 存储

目标网站：人民网健康 health.people.com.cn

"""

import requests

import time

import json

from bs4 import BeautifulSoup

def fetch_page(url):

    """

    获取指定 URL 的网页 HTML

    参数:
        url: 网页地址
    返回:
        HTML 源码字符串，失败返回 None

    """
    headers = {}

    headers["User-Agent"] = (

        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "

        "AppleWebKit/537.36 (KHTML, like Gecko) "

        "Chrome/120.0.0.0 Safari/537.36"

    )
    try:
        print("[请求] " + url)
        response = requests.get(url, headers=headers, timeout=15,verify=False)
        response.encoding = "utf-8"
        status_code = response.status_code

        if status_code != 200:
            print("  ⚠️ 状态码 " + str(status_code) + "，跳过此页")
            return None

        return response.text
    except requests.exceptions.Timeout:
        print("  ⚠️ 请求超时")
        return None
    except requests.exceptions.ConnectionError:
        print("  ⚠️ 连接失败")
        return None

  
  

def parse_news_from_page(html):

    """
    从一页的 HTML 中提取新闻列表
    参数:
        html: 网页 HTML 源码
    返回:
        (news_list, has_next_page)
        news_list:      新闻记录列表
        has_next_page:  是否有下一页（True/False）

    """

    soup = BeautifulSoup(html, "lxml")
    news_list = []
    has_next_page = False

    # 步骤1：select() 找所有新闻 a 标签

    all_news_links = soup.select('a[href*="n1/"][href*="c14739"]')

    print("  [解析] 找到 " + str(len(all_news_links)) + " 条新闻")

    # 步骤2：逐条提取

    for link_tag in all_news_links:

        href = link_tag.get("href", "")

        title = link_tag.get_text(strip=True)

        if title == "":

            continue

        # 日期在 a 标签后面的文本中

        next_text = link_tag.next_sibling

        date = ""

        if next_text is not None:

            raw_text = str(next_text).strip()

            import re

            m = re.search(r'(\d{4}-\d{2}-\d{2})', raw_text)

            if m is not None:

                date = m.group(1)

        # 备用：从父 li 中找日期

        if date == "":

            parent_li = link_tag.parent

            if parent_li is not None and parent_li.name == "li":

                li_text = parent_li.get_text()

                import re

                m = re.search(r'(\d{4}-\d{2}-\d{2})', li_text)

                if m is not None:

                    date = m.group(1)

        if title != "" and href != "":

            item = {}

            item["标题"] = title

            item["链接"] = href

            item["日期"] = date

            news_list.append(item)

        # 步骤3：判断是否有下一页

    # 不匹配"下一页"文字（可能有编码问题），改用数字分页判断

    page_links = soup.select(".page_n a")

    for link in page_links:

        link_text = link.get_text(strip=True)

        # 如果链接文字是数字（如 "2", "3"），说明有下一页

        # .isdigit() 方法：判断字符串是否全是数字

        if link_text.isdigit():

            has_next_page = True

            break

    return news_list, has_next_page

def build_page_url(base_url, page_num):

    """构造第 page_num 页的 URL"""

    if page_num == 1:

        return base_url

    return base_url.replace("index.html", "index" + str(page_num) + ".html")

def main():

    print("=" * 60)
    print("   人民网健康 - 滚动新闻翻页爬取")
    print("=" * 60)
    print()

    base_url = "https://health.people.com.cn/GB/415859/index.html"
 
    all_news = []

    page = 1

    while page <= 10:

        url = build_page_url(base_url, page)   # 统一用这个
        print("--- 第 " + str(page) + " 页 ---")
        html = fetch_page(url)
        if html is None:

            page = page + 1

            continue

        news, has_next = parse_news_from_page(html)

        print("  提取 " + str(len(news)) + " 条")

        all_news.extend(news)

        if has_next == False:

            print(">> 已到最后一页")

            break
        time.sleep(3)

        page = page + 1

    print()

    print("=" * 60)

    print("共获取 " + str(len(all_news)) + " 条新闻")

    print("=" * 60)

    filename = "health_news.json"

    fh = open(filename, "w", encoding="utf-8")

    json.dump(all_news, fh, ensure_ascii=False, indent=2)

    fh.close()

    print("已保存: " + filename)

if __name__ == "__main__":

    main()
```

## 项目总结

| 知识点 | 内容 |
|--------|------|
| BeautifulSoup | `BeautifulSoup(html, "lxml")` |
| find / find_all | 按标签+class定位 |
| select / select_one | CSS选择器 |
| 节点遍历 | children / descendants / sibling / parent |

### BS4 vs 正则

| | 正则 | BS4 |
|------|------|-----|
| 难度 | 记特殊字符 | 记class名 |
| 代码 | 每个字段独立正则 | select_one一步 |
| 适应 | 结构变就废 | class变改一处 |
| 关联 | 无层级 | children/sibling/parent |

> 简单固定结构 → 正则。多字段层级翻页 → BS4。
