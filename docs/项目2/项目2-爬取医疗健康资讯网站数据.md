# 项目2：爬取医疗健康资讯网站数据

项目 1 用“所有链接”练手。本章继续使用 BeautifulSoup，但开始用 CSS 选择器描述“我想找哪里”。

> 只处理公开页面。网站改版后选择器可能需要调整，这是爬虫学习中正常的维护工作。

## 本章任务

从公开健康资讯首页取出前 20 个标题和链接，并保存为 `health_news.json`。

## 先认识 CSS 选择器

```python
soup.select("a[href]")       # 所有带链接地址的 a 标签
soup.select(".news a")       # class 是 news 的区域里的 a 标签
soup.select("#main a")       # id 是 main 的区域里的 a 标签
soup.select("ul li a")       # ul 里面的 li 里面的 a 标签
```

刚开始不确定网页结构时，先用 `a[href]` 让程序跑通；再按 F12 把范围缩小。

## 完整代码

把下面代码保存为 `health_news.py`，或下载本章的[完整代码](health_news.py)。

```python
import json
from urllib.parse import urljoin

import requests
from bs4 import BeautifulSoup

URL = "https://health.people.com.cn/"
HEADERS = {"User-Agent": "Mozilla/5.0"}


def get_soup(url):
    response = requests.get(url, headers=HEADERS, timeout=15)
    response.raise_for_status()
    return BeautifulSoup(response.text, "html.parser")


def get_articles(soup, base_url):
    articles = []
    seen = set()

    for tag in soup.select("a[href]"):
        title = tag.get_text(" ", strip=True)
        if len(title) < 8 or title in seen:
            continue
        seen.add(title)
        articles.append({"title": title, "url": urljoin(base_url, tag["href"])})

    return articles[:20]


def main():
    articles = get_articles(get_soup(URL), URL)
    with open("health_news.json", "w", encoding="utf-8") as file:
        json.dump(articles, file, ensure_ascii=False, indent=2)
    print(f"保存完成，共 {len(articles)} 条")


if __name__ == "__main__":
    main()
```

代码的流向很简单：`get_soup()` 得到可查询的网页，`get_articles()` 变成列表，`json.dump()` 写入文件。

## 运行和检查

```bash
python health_news.py
```

打开 `health_news.json`。每一对 `{}` 是一条资讯，里面只有 `title` 和 `url` 两个字段，便于检查。

## 常见问题

| 问题 | 原因和处理 |
|---|---|
| `articles` 是空列表 | 先打印 `soup.title`，确认下载的不是错误页；再检查选择器 |
| 保存后中文变成 `\\u` | 确认有 `ensure_ascii=False` |
| 内容里混进导航文字 | 把 `a[href]` 改为新闻列表所在区域，例如 `.list a[href]` |
