## 1.1项目任务与目标

### 1.1.1 什么是爬虫？（生活化理解）

想象你去图书馆查资料。你的步骤是：

1. 走到图书馆（**发送请求**）
2. 翻看书架上的书（**获取网页内容**）
3. 找到你需要的那几段文字，抄到笔记本上（**提取有用数据**）
4. 把笔记本带回家（**保存数据**）

**爬虫做的事情一模一样**，只不过"图书馆"变成了"网站"，"抄写"变成了"程序自动提取"。

用更技术的话说：**爬虫 = 用程序自动访问网页，从网页中提取你需要的信息，然后保存下来。**

### 1.2.6 写第一段测试代码：测试网络连接

> **作用说明**：在实际爬取数据之前，我们先写一段最简单的代码，测试你的 Python 环境 + requests 库能否正常访问国家中医药管理局网站。这就像出门前先试试门能不能打开。

```python
# -*- coding: utf-8 -*-
"""
项目1：爬取国家中医药管理局时政要闻数据
第一步：测试网络连接
"""

# ============================================================
# 导入 requests 库
# ============================================================
# requests 是一个"网络通信工具"。
# 它可以帮 Python 程序像浏览器一样，向网站发请求、收数据。
# 它不是你电脑自带的，需要用 pip install requests 安装。
import requests

# ============================================================
# 设置要访问的网址
# ============================================================
# 这是国家中医药管理局的官网首页
# 注意：这个网站使用 http:// 协议（不加密），这是正常现象
url = "http://www.natcm.gov.cn/"

# ============================================================
# 设置请求头（Headers）
# ============================================================
# 请求头就像你进图书馆时出示的学生证。
# 网站看到这些信息后，才知道"哦，这是一个正常的浏览器在访问"。
# User-Agent 是最重要的一个头，告诉网站你是什么浏览器。
# 如果不设置这个，有些网站会直接拒绝你的访问。
headers = {}
headers["User-Agent"] = (
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
    "AppleWebKit/537.36 (KHTML, like Gecko) "
    "Chrome/120.0.0.0 Safari/537.36"
)

# ============================================================
# 开始测试
# ============================================================
print("=" * 50)
print("开始测试网络连接...")
print("=" * 50)

try:
    # --------------------------------------------------------
    # 发送 GET 请求
    # --------------------------------------------------------
    # requests.get() 函数：向指定网址发送一个 GET 请求
    # 参数解释：
    #   第一个参数 url     = 要访问的网址
    #   headers=headers    = 请求头，告诉网站"我是浏览器"
    #   timeout=10         = 最多等待 10 秒，超时就放弃
    # 返回值：一个 Response 对象，包含网站返回的所有信息
    response = requests.get(url, headers=headers, timeout=10)

    # --------------------------------------------------------
    # 查看状态码
    # --------------------------------------------------------
    # status_code 属性：网站返回的 HTTP 状态码
    #   200 = 成功！网站正常返回了内容
    #   404 = 你访问的页面不存在
    #   500 = 网站服务器出了问题
    status_code = response.status_code
    print("✅ 状态码: " + str(status_code))

    # --------------------------------------------------------
    # 查看网页编码
    # --------------------------------------------------------
    # encoding 属性：网页的文字编码方式
    # 中文网站一般是 utf-8 或 gb2312
    page_encoding = response.encoding
    print("📄 网页编码: " + page_encoding)

    # --------------------------------------------------------
    # 查看网页内容（只打印开头 500 个字符）
    # --------------------------------------------------------
    # response.text 属性：网站返回的网页内容（一整个 HTML 字符串）
    # 非常长，所以用 [:500] 只取前 500 个字符看看
    page_content = response.text
    print("📝 网页内容前 500 字符:")
    print(page_content[:500])

    print("=" * 50)
    print("🎉 恭喜！网络连接测试成功！")
    print("=" * 50)

# ------------------------------------------------------------
# 下面的 except 块用来处理"意外情况"
# 就像出门带伞——万一下雨（出错了），不会淋成落汤鸡
# ------------------------------------------------------------

except requests.exceptions.Timeout:
    # 等了 10 秒网站都没反应 → 超时了
    print("❌ 错误：请求超时！请检查网络连接。")
    print("   可能原因：1) 网络不通  2) 网站服务器响应慢  3) 防火墙限制")

except requests.exceptions.ConnectionError:
    # 根本连不上网站 → 网络问题
    print("❌ 错误：连接失败！请确认网址是否正确。")
    print("   可能原因：1) 网址输错了  2) DNS 解析失败  3) 网站不存在")

except Exception as e:
    # 捕获所有其他的意外错误
    # Exception 是所有异常的"父类"，能兜底捕获任何没预料到的错误
    print("❌ 发生了未知错误: " + str(e))
```

## 1.3 理解 HTTP 请求与响应

### 1.3.1 什么是 HTTP？

> **作用说明**：在正式写爬虫之前，必须先理解浏览器和网站之间是怎么"对话"的。这就像学开车前先要知道油门和刹车在哪。

**生活化理解：**

- 你在浏览器输入网址按回车，相当于你**给网站发了一封信**，说："请把你这个页面的内容发给我看看"
- 网站收到信，**回了一封信**，信里装着网页的内容（HTML 代码）
- 这在技术上叫 **HTTP 请求（Request）** 和 **HTTP 响应（Response）**

---

> **作用说明**：每个浏览器都自带"开发者工具"，可以让你看到请求和响应的详细内容。写爬虫的核心能力之一，就是会用它来分析目标网站。

### 1.3.3 看懂请求头（Request Headers）

在开发者工具右侧面板中，找到 **"Request Headers"（请求头）** 部分。

| 请求头字段             | 含义（通俗解释）                    | 你在爬虫中要不要设置？ |
| ----------------- | --------------------------- | ---------------- |
| `User-Agent`      | 告诉网站"我是什么浏览器"。就像你进图书馆时亮出学生证 | ✅ **必设**，否则容易被拒绝 |
| `Accept`          | 告诉网站"我能接收什么格式的内容"           | ⭕ 可选 |
| `Accept-Language` | 告诉网站"我偏好什么语言"               | ⭕ 可选 |
| `Cookie`          | 你的"身份标识"，用于登录状态等            | ⭕ 爬公开数据一般不需要 |
| `Referer`         | 告诉网站"我是从哪个页面跳转过来的"          | ⭕ 可选 |

### 1.3.4 GET 和 POST 的区别

> **作用说明**：HTTP 请求主要有两种类型——GET 和 POST。理解它们的区别，是写爬虫的基本功。

**生活化理解：**

| 对比维度 | GET 请求 | POST 请求 |
|---------|----------|----------|
| **比喻** | 去图书馆借书看 | 去图书馆填表提交资料 |
| **数据位置** | 数据在网址上（`?key=value`） | 数据在请求"身体"里（不可见） |
| **用途** | 获取信息（查新闻、看公告） | 提交信息（登录、搜索、评论） |
| **可见性** | 参数在网址栏可见 | 参数网址栏看不到 |
| **我们的项目** | ✅ 主要使用 GET，获取新闻列表 | 如果网站有搜索框，搜索时用 POST |

### 1.3.6 实战：用 requests.get() 获取时政要闻页面

> **作用说明**：现在我们要把刚才在浏览器里看到的东西，用 Python 代码"拿"过来。


**将 `spider.py` 中的代码替换为以下内容：**

```python
# -*- coding: utf-8 -*-
"""
项目1：爬取国家中医药管理局时政要闻数据
第二步：获取时政要闻页面的源码
"""
import requests

# ============================================================
# 1. 准备工作：设置请求头，伪装成浏览器
# ============================================================
headers = {}
headers["User-Agent"] = (
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
    "AppleWebKit/537.36 (KHTML, like Gecko) "
    "Chrome/120.0.0.0 Safari/537.36"
)
headers["Accept"] = "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8"

# 目标网址：国家中医药管理局"时政要闻"栏目
url = "http://www.natcm.gov.cn/xinxifabu/shizhengyaowen/"

# ============================================================
# 2. 发送 GET 请求
# ============================================================
print(">>> 正在访问国家中医药管理局时政要闻栏目...")
print(">>> 目标网址: " + url)
print()

try:
    # 发送 GET 请求，timeout=15 表示最多等 15 秒
    response = requests.get(url, headers=headers, timeout=15)
	#网站源码转码，一般都是utf-8编码

    response.encoding = 'utf-8'
    # ============================================================
    # 3. 检查请求是否成功
    # ============================================================
    status_code = response.status_code
    print(">>> HTTP 状态码: " + str(status_code))

    if status_code == 200:
        print("✅ 请求成功！网页内容已获取。")
    else:
        print("⚠️ 状态码异常 (" + str(status_code) + ")，请检查网络或网址。")
        # exit(1) 的意思是：程序以"失败"状态退出，后面的代码不再执行
        exit(1)

    # ============================================================
    # 4. 查看网页基本信息
    # ============================================================
    page_encoding = response.encoding
    content_length = len(response.text)
    print(">>> 网页编码: " + page_encoding)
    print(">>> 网页内容总长度: " + str(content_length) + " 个字符")
    print()

    # ============================================================
    # 5. 打印网页内容的部分内容（只打前 1500 个字符）
    # ============================================================
    print("=" * 60)

    print("=" * 60)

    # ============================================================
    # 6. 将网页内容保存到文件（方便后续分析和验证）
    # ============================================================
    # open() 函数：打开一个文件，准备写入
    #   第一个参数 "page_source.html" = 文件名

except requests.exceptions.Timeout:
```

## 1.4 正则表达式提取数据

> **作用说明**：现在我们已经拿到了网页的 HTML 源码，接下来需要从中"捞"出有用的信息——新闻标题、发布时间、详情链接。这就要用到**正则表达式**，它是文本处理的"瑞士军刀"。

### 1.4.1 什么是正则表达式？（生活化理解）

想象你在一个装满杂物的抽屉（网页源码）里找东西：

- 找所有**手机号**（11 位数字）→ 你需要一个"匹配 11 位数字"的规则
- 找所有**邮箱地址**（xxx@xxx.com）→ 你需要一个"匹配邮箱格式"的规则
- 找所有**日期**（2026-07-07）→ 你需要一个"匹配 YYYY-MM-DD 格式"的规则

**正则表达式就是用来描述这些"匹配规则"的语言。**

---

### 1.4.2 正则基础：你需要记住的核心语法

> **作用说明**：不需要学全部正则语法，本项目只用以下核心语法就够。

| 正则符号 | 含义 | 示例 | 能匹配什么？ |
|----------|------|------|-------------|
| `.` | 匹配**任意一个**字符（除了换行） | `a.c` | `abc`、`a1c`、`a c` |
| `*` | 前面的东西出现 **0 次或多次** | `ab*c` | `ac`、`abc`、`abbc` |
| `+` | 前面的东西出现 **1 次或多次** | `ab+c` | `abc`、`abbc`（不匹配 `ac`） |
| `?` | 前面的东西出现 **0 次或 1 次** | `ab?c` | `ac`、`abc` |
| `()` | **分组**，把匹配的内容"抓"出来 | `(\d+)-(\d+)` | 捕获年、月两组数字 |
| `.*?` | **非贪婪匹配**（最短匹配） | `<a>(.*?)</a>` | 匹配最短的 `<a>` 标签内容 |
| `\d` | 匹配一个数字（0-9） | `\d{3}` | `123`、`456` |
| `\w` | 匹配一个字母/数字/下划线 | `\w+` | `hello`、`abc123` |
| `\s` | 匹配一个空白字符（空格、换行等） | `a\sb` | `a b` |
| `[^x]` | 匹配**不是 x** 的任意字符 | `[^"]+` | 匹配"非双引号"的任意字符 |

**最关键的区别 —— 贪婪 vs 非贪婪：**

这是新手最容易踩的坑。假设有这样一段 HTML：

```html
<a href="1.html">新闻A</a>  <a href="2.html">新闻B</a>
```

| 正则 | 匹配结果 | 解释 |
|------|---------|------|
| `<a href="(.*)">` | `1.html">新闻A</a>  <a href="2.html` | ❌ 贪婪：一路吃到最后一个 `">` |
| `<a href="(.*?)">` | `1.html`（第一个）、`2.html`（第二个） | ✅ 非贪婪：遇到第一个 `">` 就停 |

> 🔑 **记住：写爬虫时，除非你就是想要匹配全部内容，否则一律用 `.*?` 而不要用 `.*`！**

### 1.4.3 Python 中使用正则表达式

> **作用说明**：Python 通过 `re` 模块（内置，不需要安装）来使用正则。

**三个最常用的函数：**

```python
import re

# 1. re.findall(pattern, text)
#    查找所有匹配的内容，返回一个列表
#    适合：提取页面中所有的新闻条目
text = "电话: 13800138000, 手机: 13900139000"
phones = re.findall(r'\d{11}', text)
print(phones)  # 输出: ['13800138000', '13900139000']

# 2. re.search(pattern, text)
#    查找第一个匹配的内容，返回一个 Match 对象
#    适合：从每条新闻的 HTML 片段中提取标题、链接、日期
html_fragment = '<a href="detail.html">新闻标题</a>'
match = re.search(r'href="([^"]+)"', html_fragment)
if match:
    print(match.group(1))  # 输出: detail.html

# 3. re.sub(pattern, replacement, text)
#    把匹配的内容替换掉
#    适合：清理 HTML 标签，得到纯文本
html_text = "<p>这是一段<b>重要</b>内容</p>"
clean = re.sub(r'<[^>]+>', '', html_text)
print(clean)  # 输出: 这是一段重要内容
```

### 1.4.5 逐步写出正则表达式

> **作用说明**：现在根据上面分析的结构，一步步写出正则表达式。注意：我们不写一个"超级正则"，而是**每一步只匹配一个字段**，拆开写更容易理解和调试。

**第一步：找到所有 a 标签和日期组合**

每条新闻的核心 HTML 片段是这样的：

```html
<a href="链接" title="标题">标题</a> <span>日期</span>
```

我们先写一个简单的正则，把页面上所有的 `<a>` 标签都找出来。

```python
# 匹配一个完整的 a 标签（从 <a 开始到 </a> 结束）
# 注意：用 .*? 而不是 .*，因为我们要最短匹配
a_tag_pattern = r'<a[^>]*>.*?</a>'
```

**第二步：从每个 a 标签中提取链接（href）**

```python
# href 的值在双引号中
# [^"] 表示"任何不是双引号的字符"
# [^"]+ 表示"一个或多个非双引号的字符"（就是链接本身）
# 括号 () 表示"把这一部分捕获出来，我后面要用"
href_pattern = r'href="([^"]+)"'
```

**第三步：从每个 a 标签中提取标题（title）**

```python
# title 的值也在双引号中，写法跟 href 一样
title_pattern = r'title="([^"]+)"'
```

**第四步：从 a 标签后面的 span 标签中提取日期**

```python
# 日期格式固定为 YYYY-MM-DD
# \\d 表示任意数字（0-9）
# \\d{4} 表示正好 4 个数字（年份）
# \\d{2} 表示正好 2 个数字（月份/日期）
date_pattern = r'<span[^>]*>(\\d{4}-\\d{2}-\\d{2})</span>'
```

**把这四步串起来的过程：**

1. 从整页 HTML 中，找到每条 `<a>...</a> <span>...</span>` 组合
2. 对每一条，用三个小正则分别提取：链接、标题、日期
3. 每个字段独立提取，清晰易懂

### 1.4.6 实战：完整的数据提取代码

📸 操作截图：清空 spider.py 准备粘贴新代码 | 截取范围：VS Code 编辑区 | 重点标注：红框圈出空白编辑区域

```python
# -*- coding: utf-8 -*-
"""
项目1：爬取国家中医药管理局时政要闻数据
第三步：用正则表达式提取新闻标题、时间和链接
"""
import re

# ============================================================
# 1. 读取网页源码
# ============================================================
print(">>> 正在读取网页源码...")

try:
    # 打开 page_source.html 文件，以 utf-8 编码读取
    # "r" 表示 read 模式（只读）
    file_handle = open("page_source.html", "r", encoding="utf-8")
    # read() 方法：把整个文件内容读成一个字符串
    html_content = file_handle.read()
    file_handle.close()
    # len() 函数：返回字符串的长度（有多少个字符）
    file_size = len(html_content)
    print("✅ 读取成功！文件大小: " + str(file_size) + " 个字符")
except FileNotFoundError:
    print("❌ 找不到 page_source.html 文件！")
    print("   请先运行第二步的代码生成这个文件。")
    exit(1)

print()

# ============================================================
# 2. 正则分步提取
# ============================================================
# 每条新闻的 HTML 结构：
#   <li>
#     <a href="链接" title="标题">标题</a> <span>YYYY-MM-DD</span>
#   </li>
#
# 我们不写一个"超级正则"一次性匹配所有字段。
# 而是分两步：
#   第 2 步 a：找到页面上所有"a 标签 + span 标签"的组合
#   第 2 步 b：对每个组合，分别提取链接、标题、日期

# ------------------------------------------------------------
# 步骤 2a：找到所有新闻条目（每个 li 块）
# ------------------------------------------------------------
# re.compile() 函数：把正则表达式"编译"成一个可以复用的规则对象
#   参数1：正则表达式字符串
#         r' 开头表示"原始字符串"，里面的反斜杠不会被转义
#   re.DOTALL：一个选项标志，让 . 也能匹配换行符 \n
#              （因为 HTML 标签通常跨多行）
li_pattern = re.compile(r'<li>(.*?)</li>', re.DOTALL)

# findall() 方法：在目标文字中查找所有匹配的片段，返回一个列表
#   参数1：要搜索的文字（整个 HTML 源码）
#   返回值：一个列表，每个元素是一个匹配到的字符串
all_li_blocks = li_pattern.findall(html_content)
print(">>> 找到 " + str(len(all_li_blocks)) + " 个 li 标签块")

# ------------------------------------------------------------
# 步骤 2b：从每个 li 块中逐个提取链接、标题、日期
# ------------------------------------------------------------
# 小正则1：匹配 href 属性中的链接
href_pattern = re.compile(r'href="([^"]+)"')
#   ([^"]+) = 双引号里的任意字符（就是链接地址），括号表示"捕获"
#   为什么用 [^"]+ 而不是 .*? ？因为链接里不可能有双引号，
#   所以 [^"]+ 更安全，不会跨过双引号边界

# 小正则2：匹配 title 属性中的标题
title_pattern = re.compile(r'title="([^"]+)"')
#   和 href 一样的写法，从双引号里提取文本

# 小正则3：备选方案 —— 如果 a 标签没有 title 属性，
#   就提取 a 标签内部的文本作为标题
#   <a ...>这里的文字</a>
inner_text_pattern = re.compile(r'<a[^>]*>([^<]+)</a>')
#   ([^<]+) = 一个或多个"不是 <"的字符，即标签内部的文字

# 小正则4：匹配 YYYY-MM-DD 格式的日期
date_pattern = re.compile(r'(\d{4}-\d{2}-\d{2})')
#   \d{4} = 正好4个数字（年份）
#   \d{2} = 正好2个数字（月份、日期）

# 用于存储所有提取结果的列表
news_list = []

print(">>> 开始逐条提取...")
print()

# 遍历每个 li 块
for li_block in all_li_blocks:

    # --- 提取链接 ---
    # re.search() 函数：在文字中查找第一个匹配的位置
    #   参数1：正则规则（我们提前编译好的 pattern 对象）
    #   参数2：要搜索的文字
    #   返回值：如果找到了，返回一个 Match 对象；没找到返回 None
    link_match = href_pattern.search(li_block)
    if link_match is not None:
        # .group(1) 方法：取出第一个捕获组的内容
        # 参数 0 = 整个匹配到的文本
        # 参数 1 = 第一个括号 () 捕获的内容
        href = link_match.group(1)
    else:
        href = ""

    # --- 提取标题 ---
    # 优先用 title 属性（通常更完整）
    title_match = title_pattern.search(li_block)
    if title_match is not None:
        title = title_match.group(1)
    else:
        # 备选：用 a 标签内部的文字
        inner_match = inner_text_pattern.search(li_block)
        if inner_match is not None:
            title = inner_match.group(1)
        else:
            title = ""

    # --- 清洗标题 ---
    # .strip() 方法：去掉字符串两端的空白（空格、换行、tab 等）
    title = title.strip()
    # re.sub() 函数：把字符串中匹配正则的部分替换掉
    #   参数1：正则规则
    #   参数2：替换成什么
    #   参数3：在哪个字符串上操作
    #   这里把标题中多个连续的空白合并成一个普通空格
    title = re.sub(r'\s+', ' ', title)

    # --- 提取日期 ---
    date_match = date_pattern.search(li_block)
    if date_match is not None:
        date = date_match.group(1)
        date = date.strip()  # 去掉可能的前后空白
    else:
        date = ""

    # --- 处理链接：把相对路径转成完整 URL ---
    # 网页里的链接是 /xinxifabu/.../38302.html
    # 浏览器里需要的是 http://www.natcm.gov.cn/xinxifabu/.../38302.html
    if href.startswith('/'):
        # .startswith() 方法：判断字符串是否以某个前缀开头
        # 以 / 开头说明是相对路径，需要补上域名
        full_link = 'http://www.natcm.gov.cn' + href
    else:
        full_link = href

    # --- 只保留三个字段都有效的记录 ---
    # 如果标题为空、链接为空、日期为空，就不存
    if title != "" and full_link != "" and date != "":
        # 创建一个字典，存一条新闻的三个字段
        news_item = {}
        news_item["标题"] = title
        news_item["发布时间"] = date
        news_item["链接"] = full_link
        # 把这条记录加到总列表里
        news_list.append(news_item)

print(">>> 有效新闻记录: " + str(len(news_list)) + " 条")
print()

# ============================================================
# 3. 打印提取结果（表格形式）
# ============================================================
# 我们一步步构建表格，不写复杂的占位符对齐代码
print("=" * 80)

# 打印表头
header_line = "序号  标题                                                  发布时间"
print(header_line)
print("=" * 80)

# 逐行打印
for index in range(len(news_list)):
    # 序号从 1 开始
    seq = index + 1

    # 取当前行的标题
    title_display = news_list[index]["标题"]
    # 如果标题太长（超过 52 个字符），截断并加 "..."
    if len(title_display) > 52:

    # 取当前行的日期

    # str() 函数：把数字转成字符串

print("=" * 80)
print("✅ 共提取 " + str(len(news_list)) + " 条新闻记录")
print()

# ============================================================

# ============================================================
print(">>> 前 3 条记录的完整信息（请核对数据是否正确）：")
print("-" * 80)

# 只显示前 3 条（如果没有 3 条就全显示）
show_count = 3
if len(news_list) < show_count:
    show_count = len(news_list)

for i in range(show_count):
    item = news_list[i]

    print()
```

### 1.5.2 代码分块讲解

#### 函数 1：`fetch_page(url)` —— 发送请求，获取网页

```python
def fetch_page(url):
    """发送 GET 请求，返回 HTML 源码"""
    # 设置请求头
    headers = {}
    headers["User-Agent"] = (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/120.0.0.0 Safari/537.36"
    )
    headers["Accept"] = "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8"

    try:
        print("[请求] 正在访问: " + url)
        # 发送 GET 请求
        response = requests.get(url, headers=headers, timeout=15)
        #网站源码转码，一般都是utf-8编码

		response.encoding = 'utf-8'
        status_code = response.status_code
        print("[请求] 状态码: " + str(status_code))

        # 200 表示成功
        if status_code == 200:
```

```python
        # 3-5 处理链接：相对路径转完整 URL
        if href.startswith('/'):
```

```python
"""
项目1：爬取国家中医药管理局时政要闻数据
完整版：请求 → 解析 → 保存

目标网站：http://www.natcm.gov.cn/xinxifabu/shizhengyaowen/

import requests
import re
import csv
import time


def fetch_page(url):
    """
    发送 GET 请求，获取网页 HTML 源码

    参数:
        url: 目标网址（字符串）
    返回:
        HTML 源码字符串，失败时返回 None
    """
    # 设置请求头 —— 告诉网站"我是浏览器"
    headers = {}
    headers["User-Agent"] = (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/120.0.0.0 Safari/537.36"
    )
    headers["Accept"] = "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8"

    try:
        print("[请求] 正在访问: " + url)

        # 发送 GET 请求
        # timeout=15 表示最多等 15 秒
        response = requests.get(url, headers=headers, timeout=15)
        #网站源码转码，一般都是utf-8编码

		response.encoding = 'utf-8'
        status_code = response.status_code
        print("[请求] HTTP 状态码: " + str(status_code))

        # 只有状态码 200 才表示成功
        if status_code == 200:
            return response.text
        else:
            print("[警告] 状态码异常 (" + str(status_code) + ")，请检查目标网址")
            return None

    except requests.exceptions.Timeout:
        # 等了 15 秒还没响应 → 超时
        print("[错误] 请求超时！网站响应太慢或网络不通。")
        return None
    except requests.exceptions.ConnectionError:
        # 根本连不上 → 网络问题
        print("[错误] 连接失败！请检查网络连接。")
        return None


def parse_news(html):
    """
    从 HTML 源码中提取新闻信息

    参数:
        html: 网页 HTML 源码（字符串）
    返回:
        新闻记录列表，每项是 {"标题": str, "发布时间": str, "链接": str}
    """
    # --------------------------------------------------------
    # 步骤 1：找到所有 li 标签块
    # --------------------------------------------------------
    # 每条新闻在一个 <li>...</li> 标签内
    # re.compile() 把正则编译成规则对象，可以重复使用
    # re.DOTALL 让 . 也能匹配换行符（HTML 标签通常跨多行）
    li_pattern = re.compile(r'<li>(.*?)</li>', re.DOTALL)

    # findall() 返回所有匹配的片段，是一个列表
    all_li_blocks = li_pattern.findall(html)
    print("[解析] 找到 " + str(len(all_li_blocks)) + " 个 li 标签块")

    # --------------------------------------------------------
    # 步骤 2：准备四个小正则，分别提取不同字段
    # --------------------------------------------------------
    # 注意：不写一个"超级正则"一次性匹配所有字段
    # 而是每个字段独立提取，更清楚、更容易调试
    #
    # 正则1：提取 href 属性中的链接
    #   [^"]+ = 一个或多个非双引号的字符（就是链接本身）
    #   括号 () = 把匹配到的内容"捕获"出来
    href_pattern = re.compile(r'href="([^"]+)"')

    # 正则2：提取 title 属性中的标题
    title_pattern = re.compile(r'title="([^"]+)"')

    # 正则3：备用方案——如果 a 标签没有 title 属性，
    #   提取 a 标签内部的文字作为标题
    inner_text_pattern = re.compile(r'<a[^>]*>([^<]+)</a>')

    # 正则4：提取 YYYY-MM-DD 格式的日期
    #   \d = 任意数字(0-9)
    #   \d{4} = 正好4个数字
    #   \d{2} = 正好2个数字
    date_pattern = re.compile(r'(\d{4}-\d{2}-\d{2})')

    # --------------------------------------------------------
    # 步骤 3：逐条处理每个 li 块
    # --------------------------------------------------------
    news_list = []

    for li_block in all_li_blocks:

        # ----- 3-1 提取链接 -----
        # search()：在文字中找第一个匹配的位置
        # 如果找到了返回 Match 对象，没找到返回 None
        link_match = href_pattern.search(li_block)
        if link_match is not None:
            # group(1)：取出第一个括号 () 捕获的内容
            href = link_match.group(1)
        else:
            href = ""

        # ----- 3-2 提取标题 -----
        # 优先用 title 属性（通常更完整、不截断）
        title_match = title_pattern.search(li_block)
        if title_match is not None:
            title = title_match.group(1)
        else:
            # 备用：用 a 标签内部的文字
            inner_match = inner_text_pattern.search(li_block)
            if inner_match is not None:
                title = inner_match.group(1)
            else:
                title = ""

        # ----- 3-3 清洗标题 -----
        # .strip()：去掉字符串两端的空白（空格、换行等）
        title = title.strip()
        # re.sub()：把匹配正则的部分替换掉
        #   \s+ = 一个或多个空白字符
        #   替换成一个普通空格 ' '
        title = re.sub(r'\s+', ' ', title)

        # ----- 3-4 提取日期 -----
        date_match = date_pattern.search(li_block)
        if date_match is not None:
            date = date_match.group(1)
            date = date.strip()
        else:
            date = ""

        # ----- 3-5 处理链接：相对路径 → 完整 URL -----
        # 网页里的链接是 /xinxifabu/.../38302.html
        # 需要补上域名变成完整网址
        # startswith('/')：判断字符串是否以 '/' 开头
        if href.startswith('/'):
            full_link = "http://www.natcm.gov.cn" + href
        else:
            full_link = href

        # ----- 3-6 筛选有效记录 -----
        # 只有三个字段都非空（有内容）才存入列表
        if title != "" and full_link != "" and date != "":
            # 创建字典，存一条新闻的三个字段
            item = {}
            item["标题"] = title
            item["发布时间"] = date
            item["链接"] = full_link
            news_list.append(item)

    print("[解析] 有效记录: " + str(len(news_list)) + " 条")
    return news_list


def save_to_csv(news_list, filename):
    """
    将新闻数据保存为 CSV 文件

    writer = csv.writer(file_handle)

    # 写入表头（CSV 文件的第一行）
    writer.writerow(["序号", "新闻标题", "发布时间", "新闻链接"])

        item = news_list[index]
        seq = index + 1
        # writerow() 接收一个列表，每个元素是一列表格数据
        writer.writerow([seq, item["标题"], item["发布时间"], item["链接"]])

    # 写入完成，关闭文件
    file_handle.close()

    print("[保存] 数据已写入 " + filename)
    print("[保存] 共 " + str(len(news_list)) + " 条记录")
```

| 状态码 | 含义 | 解决办法 |
|--------|------|---------|
