# 项目1：爬取国家中医药管理局时政要闻数据

这是第一只真正的爬虫。它只做三件事：打开一个公开网页、拿到新闻链接、保存成 CSV 文件。

> 合规提示：只采集公开页面，设置访问间隔，不采集个人信息，也不要绕过登录、验证码或访问限制。

## 你将学会什么

- 用 `requests.get()` 向网页要数据
- 用 BeautifulSoup 找到网页里的链接
- 用 `csv` 把结果保存到 Excel 可以打开的文件

## 第一步：准备环境

在终端执行一次：

```bash
pip install requests beautifulsoup4
```

新建文件 `news_spider.py`，也可以直接下载本章的[完整代码](news_spider.py)。

## 第二步：先把网页拿回来

下面四行代码的结果是一个字符串，里面装着网页的 HTML 源码。

```python
import requests

url = "https://www.satcm.gov.cn/xwzx/"
headers = {"User-Agent": "Mozilla/5.0"}
response = requests.get(url, headers=headers, timeout=15)
response.raise_for_status()
html = response.text
print(html[:200])
```

- `url` 是要访问的公开网页地址。
- `headers` 告诉网站这是普通浏览器请求。
- `timeout=15` 表示最多等 15 秒，网络卡住时程序不会一直等。
- `html[:200]` 只打印前 200 个字符，用来确认确实拿到了网页。

## 第三步：从网页里找新闻链接

网页里每个链接通常都是一个 `<a>` 标签。下面的循环把链接文字和链接地址取出来。

```python
from bs4 import BeautifulSoup
from urllib.parse import urljoin

soup = BeautifulSoup(html, "html.parser")

for link in soup.select("a[href]")[:10]:
    title = link.get_text(" ", strip=True)
    href = urljoin(url, link["href"])
    print(title, href)
```

- `select("a[href]")` 的意思是：找所有带 `href` 地址的 `<a>` 标签。
- `get_text()` 把标签中的文字拿出来。
- `urljoin()` 把网页中的相对地址补成完整地址。

## 完整代码

```python
import csv
from urllib.parse import urljoin

import requests
from bs4 import BeautifulSoup

URL = "https://www.satcm.gov.cn/xwzx/"
HEADERS = {"User-Agent": "Mozilla/5.0"}


def download_html(url):
    """下载网页，失败时让 requests 给出清楚的错误。"""
    response = requests.get(url, headers=HEADERS, timeout=15)
    response.raise_for_status()
    return response.text


def parse_news(html, base_url):
    """从所有链接中挑出文字较长的项目，取前 20 条。"""
    soup = BeautifulSoup(html, "html.parser")
    news = []
    seen = set()

    for link in soup.select("a[href]"):
        title = link.get_text(" ", strip=True)
        href = urljoin(base_url, link["href"])
        if len(title) < 8 or title in seen:
            continue
        seen.add(title)
        news.append({"标题": title, "链接": href})

    return news[:20]


def save_csv(rows, filename):
    with open(filename, "w", newline="", encoding="utf-8-sig") as file:
        writer = csv.DictWriter(file, fieldnames=["标题", "链接"])
        writer.writeheader()
        writer.writerows(rows)


def main():
    html = download_html(URL)
    news = parse_news(html, URL)
    save_csv(news, "news.csv")
    print(f"保存完成，共 {len(news)} 条，文件是 news.csv")


if __name__ == "__main__":
    main()
```

运行：

```bash
python news_spider.py
```

成功时会看到“保存完成”，同一文件夹里会出现 `news.csv`。用 Excel 打开它，就能看到标题和链接两列。

## 最容易出错的地方

| 现象 | 先这样检查 |
|---|---|
| `ModuleNotFoundError` | 再执行一次 `pip install requests beautifulsoup4` |
| 超时 | 检查网络，或把 `timeout=15` 改为 `30` |
| 标题不够准确 | 在浏览器按 F12，找到新闻区域后，把 `a[href]` 改成更具体的 CSS 选择器 |
| CSV 中文乱码 | 保持 `encoding="utf-8-sig"` 不变 |

## 小练习

1. 把 `news[:20]` 改成 `news[:10]`，只保存 10 条。
2. 给每条数据增加一列“采集时间”。提示：使用 `datetime.now()`。
3. 找到新闻列表外层的 class，缩小 `select()` 的范围。
