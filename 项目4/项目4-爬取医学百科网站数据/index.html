    项目4：爬取医学百科网站数据 —— 多页面、递归与多线程实战¶

    合规提示¶

    ⚠️ 重要：在开始本项目之前，请仔细阅读以下合规要求。

    1. 目标站点：本项目使用的目标站点为「家庭医生在线」疾病百科（https://jbk.familydoctor.com.cn/），是一个面向公众开放的合法医疗健康信息平台。
    2. robots 协议：请务必遵守目标站点的 robots.txt 规则。本项目在编写前已检查该站点的 robots.txt，确认疾病百科页面允许爬虫访问。
    3. 请求频率控制：本项目将在代码中加入 time.sleep() 控制请求间隔，严禁高频率短时间大量请求，避免对目标服务器造成负担。多线程部分会特别强调使用 ThreadPoolExecutor 限制最大并发数。
    4. 数据范围：本项目仅爬取网站公开的疾病名称、症状描述、科普图片等非隐私公开信息。绝对不涉及用户隐私数据、患者个人信息、登录后的非公开内容。
    5. 数据用途：爬取的数据仅用于学习和个人研究，不得用于商业用途或大规模公开传播。

    请在确保理解以上合规要求后，再开始本项目的学习。

    4.1 项目任务 —— 理解网站树结构，制定爬取策略¶

    4.1.1 本项目要做什么¶

    在之前的项目中，你已经学会了如何爬取单个页面的数据——只要给你一个 URL，你就能把页面上的文字和图片扒下来。

    但现实中的网站不是只有一个页面的。像医学百科这种网站，它像一本厚厚的医学词典：首页是目录，点进去是各个科室（内科、外科、妇科……），每个科室下面又有几十上百种疾病，每种疾病又有自己的详情页。

    如果让你手动去点每一个链接，复制粘贴每一个疾病的信息，你可能要花几天甚至几周。

    本项目的目标就是：让程序自动遍历整个疾病百科网站，按照一定的策略把成千上万个疾病的名称、症状、图片全部收集下来。

    要做到这一点，你需要学习四个新技能：

    1. 理解网站的树形结构（把网站想象成一棵倒着长的树）
    2. 递归爬取（程序自己找链接、自己往里钻）
    3. 多页面管理（用 URL 队列管理成百上千个待爬链接）
    4. 多线程加速（同时开多个爬虫，把下载速度提升 3-5 倍）

    听起来很吓人？别怕，我们用一个你每天都做的事情来类比。

    4.1.3 两种爬取策略：深度优先 vs 广度优先¶

    知道网站是一棵树之后，问题来了：按什么顺序访问每一个页面？

    还是用书架来理解。

    策略一：深度优先（DFS —— Depth-First Search）¶

    你是一个特别专注的人。 你站到"文学类"书架前，从第一个格子开始，把里面的每一本书都翻一遍，看完一本才看下一本。第一个格子看完了，再看第二个格子……直到把"文学类"整个书架看完，你才走到"科学类"书架前。

    访问顺序：
首页 → 内科第1页 → 空调病 → 高山病 → 老年高血压 → ...（内科全看完）
     → 内科第2页 → 特发性水肿 → ...（内科全看完）
     → ...（内科所有页看完）
     → 外科第1页 → ...（外科全看完）
     → ...（一个科室彻底看完，再看下一个）

    特点：一条路走到底，不回头。先深入一个科室，把这个科室的所有疾病都爬完。

    策略二：广度优先（BFS —— Breadth-First Search）¶

    你是一个喜欢先看目录的人。 你先扫一遍"文学类"书架的第一本书的封面，然后走到"科学类"书架看第一本书的封面，再走到"历史类"书架……先把每个书架的第一本书浏览一遍，然后再回来逐个细读。

    访问顺序：
首页 → 内科第1页 → 外科第1页 → 眼科第1页 → 耳鼻喉科第1页 → ...（所有科室第1页）
     → 内科第2页 → 外科第2页 → ...（所有科室第2页）
     → 空调病 → 高山病 → ...（逐个疾病详情页）

    特点：一层一层地推进，先把同一层的信息收集齐，再进入下一层。

    本项目选哪种？¶

    对于医学百科，我们选择深度优先（DFS）。原因很简单： - 每个科室的数据是独立的，内科和外科之间没有依赖关系 - 深度优先天然适合后面要学的多线程——每个线程单独负责一个科室，互不干扰 - 爬取过程中如果程序中断，已经完整爬完的科室数据不会丢失

    4.2 递归爬取 —— 深度优先 vs 广度优先，实现疾病分类树遍历¶

    4.2.1 什么是递归¶

    递归这个词听起来高深，其实你每天都在用。

    想一想，你是怎么算 5 + 4 + 3 + 2 + 1 的？

    很多人会这么想：

    要算 5+4+3+2+1
= 5 加上 (4+3+2+1 的结果)
  而 4+3+2+1
  = 4 加上 (3+2+1 的结果)
    而 3+2+1
    = 3 加上 (2+1 的结果)
      而 2+1
      = 2 加上 (1 的结果)
        而 1 的结果就是 1

    这就是递归！递归就是：一个函数在自己的肚子里调用自己，每次调用时处理的问题比上一次小一点，直到问题小到可以直接解决为止。

    4.2.2 递归的两个必要条件¶

    每一个递归函数，必须有两个零件：

    1. 终止条件（Base Case）：也叫"递归的刹车"。没有它，函数会无限调用自己，最终程序崩溃。
    2. 递归步骤（Recursive Step）：把大问题拆成一个小问题 + 一个和自己一样但规模更小的子问题。

    用爬取医学百科来举例：

    • 终止条件：当前页面的页码超过最大页数（比如内科只有 50 页，第 51 页就停了）
    • 递归步骤：爬取当前页面上的所有疾病链接 → 然后页码 +1，调用自己爬下一页

    4.2.3 先写一个简单的递归函数（非爬虫）¶

    在接触爬虫递归之前，我们先写一个最简单的递归函数，帮你建立感觉。

    # ========================================
# 第一个递归函数：从 n 加到 1
# ========================================

def sum_n_to_1(n):
    """
    功能：计算 n + (n-1) + (n-2) + ... + 1 的结果

    参数：
        n: 一个正整数

    返回：
        累加的结果，一个整数
    """
    # 【终止条件】如果 n 等于 1，问题已经小到可以直接解决
    # 1 加到 1 的结果就是 1
    if n == 1:
        print("触底了！n = 1，返回 1")
        return 1

    # 【递归步骤】把大问题拆成小问题
    # 当前 n + 比 n 小 1 的那部分的结果
    print("当前 n = " + str(n) + "，我把 " + str(n) + " 放在一边，先去算 sum_n_to_1(" + str(n - 1) + ")")
    # 注意：下面这行就是递归调用 —— sum_n_to_1 函数在自己的肚子里调用自己
    smaller_result = sum_n_to_1(n - 1)
    # 把小问题的结果加上当前的 n，就是这个大问题的答案
    result = n + smaller_result
    print("n = " + str(n) + " 时，smaller_result = " + str(smaller_result) + "，所以 result = " + str(result))
    return result


# 测试一下
final_result = sum_n_to_1(5)
print("")
print("最终结果：1 + 2 + 3 + 4 + 5 = " + str(final_result))

    4.2.4 递归爬取的实现 —— 用 DFS 遍历内科所有疾病列表页¶

    好，现在把递归思想用到爬虫上。

    我们要做的事情： 1. 给定一个科室的第 1 页 URL 2. 爬取这一页上的所有疾病详情链接 3. 页码 +1，去爬下一页 4. 直到某一页返回 404（没有更多页面了），停止递归

    先来理解 URL 的规律。在浏览器里打开内科第1页：

    https://jbk.familydoctor.com.cn/category_1_0_1.html

    然后点"下一页"，观察 URL 变化：

    • 第1页：category_1_0_1.html
    • 第2页：category_1_0_2.html
    • 第3页：category_1_0_3.html

    你看出来了吗？URL 最后的数字就是页码。 这意味着我们可以通过修改数字来构造任意一页的 URL。

    import requests
from bs4 import BeautifulSoup
import time

# ========================================
# 准备工作：定义请求头
# ========================================

# 创建一个字典，模拟浏览器发送请求
# User-Agent 告诉服务器"我是什么浏览器"
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
}

# ========================================
# 用于存储所有疾病详情 URL 的列表
# ========================================
all_disease_urls = []

# ========================================
# 递归深度限制
# ========================================
# 设置这个变量的目的是防止程序无限递归下去
# 如果某个科室的页数超过 100 页，说明可能出了问题（比如翻页逻辑有 bug）
# 这个变量就是"安全刹车"
MAX_PAGE = 50


def crawl_category_dfs(category_id, page_num, max_depth):
    """
    深度优先爬取一个科室的所有列表页，收集所有疾病详情页链接。

    参数：
        category_id: 科室的 ID 数字
                     例如：1=内科, 2=外科, 58=眼科
        page_num:    当前要爬的页码，从 1 开始
        max_depth:   最大递归深度（防止无限递归的安全锁）

    返回：
        无。爬取到的链接会存入全局列表 all_disease_urls 中。
    """
    # ---- 终止条件 1：超过最大深度 ----
    # 如果递归深度超过限制，立刻停止，防止无限循环
    if page_num > max_depth:
        print("已达到最大递归深度 " + str(max_depth) + "，停止爬取")
        return

    # ---- 终止条件 2：超过我们设定的安全上限 ----
    if page_num > MAX_PAGE:
        print("已达到安全上限 " + str(MAX_PAGE) + " 页，停止爬取")
        return

    # ---- 构造当前页的 URL ----
    # URL 格式: category_{科室ID}_0_{页码}.html
    # 例如：category_1_0_3.html 表示内科第3页
    current_url = "https://jbk.familydoctor.com.cn/category_" + str(category_id) + "_0_" + str(page_num) + ".html"
    print("")
    print("=" * 60)
    print("正在爬取: " + current_url)
    print("=" * 60)

    # ---- 发送 HTTP 请求 ----
    # requests.get() 发送 GET 请求到目标 URL
    # 参数1：要访问的网址
    # 参数2：headers，请求头字典（模拟浏览器身份）
    # 参数3：timeout，超时时间（秒），超过这个时间没响应就放弃
    response = requests.get(current_url, headers=headers, timeout=15)

    # ---- 终止条件 3：页面不存在 ----
    # 如果状态码不是 200，说明没有更多页面了
    # HTTP 状态码 200 表示"请求成功"
    if response.status_code != 200:
        print("页面不存在（状态码: " + str(response.status_code) + "），递归结束")
        return

    # ---- 检查页面长度 ----
    # 如果返回的 HTML 内容特别短（小于1000字符），可能被拦截或页面无效
    html_length = len(response.text)
    print("页面长度: " + str(html_length) + " 字符")
    if html_length < 1000:
        print("页面内容过短，可能被拦截，递归结束")
        return

    # ---- 解析 HTML ----
    # BeautifulSoup 用于解析 HTML 字符串
    # 参数1：HTML 文本
    # 参数2："html.parser"，指定使用 Python 内置的 HTML 解析器
    soup = BeautifulSoup(response.text, "html.parser")

    # ---- 第一步：找到所有 a 标签 ----
    # soup.find_all() 查找所有匹配的标签
    # 参数1：标签名称 "a"（a 标签就是超链接 <a href="...">文字</a>）
    # 返回：包含所有 a 标签的列表
    all_a_tags = soup.find_all("a")
    print("当前页共有 " + str(len(all_a_tags)) + " 个 a 标签")

    for a_tag in all_a_tags:

        # 条件2：链接文字不为空（排除空链接）
        if "/info" in href_value and len(link_text) > 0:
            # ---- 第三步：拼出完整的绝对 URL ----
            # href 可能是相对路径 "/info10660/"，需要补全为绝对 URL
            full_url = ""
            if href_value.startswith("http"):
                # 如果已经是完整的 URL，直接使用
                full_url = href_value
            else:
                # 如果是相对路径，在前面加上网站域名

                "name": link_text,
                "url": full_url

            else:

            disease_info = {"name": link_text, "url": full_url}
            disease_list.append(disease_info)

    return disease_list


def crawl_bfs_all_departments(department_ids, max_page_per_dept):

    广度优先：先爬所有科室的第1页，再爬所有科室的第2页...

        max_page_per_dept:   每个科室最多爬多少页

        所有疾病链接的列表

    # 外层循环：按页码递增
    # 第一轮：page=1，爬所有科室的第1页
    # 第二轮：page=2，爬所有科室的第2页
    # 依此类推
    for page_num in range(1, max_page_per_dept + 1):
        print("")
        print("=" * 60)
        print("BFS 第 " + str(page_num) + " 轮：爬取所有科室的第 " + str(page_num) + " 页")
        print("=" * 60)

        round_got_any = False  # 这一轮是否有收获

        for dept_id in department_ids:
            # 爬取该科室的这一页
            # 注意：这里调用的是普通函数，不是递归
            page_results = crawl_single_page(dept_id, page_num)

            if len(page_results) > 0:
                round_got_any = True
                # 把结果追加到总结果中
                for disease in page_results:
                    all_results.append(disease)
                print("    科室 " + str(dept_id) + " 第" + str(page_num) + "页：找到 " + str(len(page_results)) + " 个疾病")

            # 每次请求后礼貌等待
            time.sleep(0.5)

        # 如果这一轮所有科室都没有返回数据，说明已经全部爬完
        if round_got_any == False:
            print("所有科室都没有第 " + str(page_num) + " 页了，停止")
            break

    return all_results

    4.2.8 递归深度限制 —— 防止无限循环¶

    在爬虫中，递归有一个特殊风险：如果翻页逻辑有问题，程序可能一直递归下去，永远不停。

    比如，某些网站即使到了最后一页，"下一页"按钮仍然存在，点击后会一直循环回第一页。

    我们已经在代码中加了三个终止条件：

    # 安全锁 1：代码中的硬上限
MAX_PAGE = 50

# 安全锁 2：函数参数中的最大递归深度
if page_num > max_depth:
    return

# 安全锁 3：HTTP 状态码检查
if response.status_code != 200:
    return

    此外，Python 本身也有递归深度保护——默认最多递归 1000 层。超过这个层数，Python 会自动报错 RecursionError，程序崩溃但不会无限运行。

    如果你想修改这个限制，可以使用 sys.setrecursionlimit()，但在学习阶段不建议修改。

    4.3 多页面爬取 —— 列表页 → 详情页，构造 URL 队列¶

    4.3.1 从"爬一页"到"爬整个科室"¶

    在 4.2 节中，我们的 DFS 爬虫已经能把内科所有疾病列表页上的链接收集出来了。但这只是第一步——我们收集到的只是一堆 URL。

    真正的多页面爬取包括两个阶段：

    阶段一（已完成）：列表页爬取
  科室首页 → 第1页 → 第2页 → ... → 第N页
  从中提取所有疾病详情页的 URL

阶段二（本节的焦点）：详情页爬取
  取一个 URL → 访问疾病详情页 → 提取疾病名称、症状、图片
                → 取下一个 URL → 重复...

    4.3.2 什么是 URL 队列¶

    想象一下：你去银行办事，先在大堂取一个号。如果前面有人，你就排队等着。窗口叫到你的号，你去办事；下一个号接着叫。

    URL 队列就是这个"排队系统"。我们用 Python 的 list（列表）来模拟这个队列：

    队列（先进先出）:
┌──────┬──────┬──────┬──────┬──────┐
│ URL1 │ URL2 │ URL3 │ URL4 │ URL5 │  ← 队尾（新来的排这里）
└──────┴──────┴──────┴──────┴──────┘
   ↑
  队头（先来的先处理）
    • 入队：把新的 URL 加到列表末尾 .append()
    • 出队：从列表开头取一个 URL .pop(0)
    • 队列为空：所有 URL 都处理完了 len(queue) == 0

    光说概念不够直观，我们直接写一段代码，把 4.2 节 DFS 收集到的 all_disease_urls 列表变成真正的 URL 队列：

    # ========================================
# 把 DFS 收集到的链接列表，装进 URL 队列
# ========================================

# 假设 all_disease_urls 是 4.2 节 DFS 收集到的结果
# 它的结构是：[{"name": "空调病", "url": "https://..."}, {"name": "高山病", "url": "https://..."}, ...]

# 第一步：创建一个空队列（就是一个空列表）
url_queue = []

# 第二步：把 all_disease_urls 里的每一个链接，逐个放入队列
# 这个循环的作用是"把待办事项全部放进排队系统"
for disease_item in all_disease_urls:
    # .append() 把元素加到列表末尾（相当于排到队尾）
    url_queue.append(disease_item)

# 第三步：验证队列是否正确装满
print("队列初始化完成！")

    先写一个函数，专门负责爬取一个疾病详情页的内容。

    import requests
from bs4 import BeautifulSoup
import time

# 请求头
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
}


def crawl_disease_detail(detail_url):
    """
    爬取一个疾病详情页，提取疾病名称、症状描述、图片链接。

    参数：
        detail_url: 疾病详情页的完整 URL
                    例如：https://jbk.familydoctor.com.cn/info10660/

    返回：
        一个字典，包含以下键：
            "name":     疾病名称（字符串）
            "symptoms": 症状描述（字符串）
            "images":   图片链接列表（列表，每个元素是字符串）
        如果爬取失败，返回 None
    """
    print("正在爬取详情页: " + detail_url)

    # ---- 发送请求 ----
    response = requests.get(detail_url, headers=headers, timeout=15)

    # 检查是否成功
    if response.status_code != 200:
        print("  请求失败，状态码: " + str(response.status_code))
        return None

    # ---- 解析 HTML ----
    soup = BeautifulSoup(response.text, "html.parser")

    # ---- 第一步：提取疾病名称 ----
    # 疾病名称通常在 <h1> 标签中
    # soup.find() 查找第一个匹配的标签，和 find_all() 不同，它只返回第一个
    # 参数1：标签名称 "h1"
    h1_tag = soup.find("h1")
    disease_name = ""
    if h1_tag is not None:
        # .get_text() 提取标签内的纯文本
        # strip=True 去掉两端空白
        disease_name = h1_tag.get_text(strip=True)
        print("  疾病名称: " + disease_name)
    else:
        # 如果没找到 h1，尝试从 <title> 标签获取
        title_tag = soup.find("title")
        if title_tag is not None:
            disease_name = title_tag.get_text(strip=True)
        else:
            disease_name = "未知疾病"

    # ---- 第二步：提取症状描述 ----
    # 把所有 <p> 标签的文字拼接起来
    # <p> 标签是 HTML 中的段落标签
    all_p_tags = soup.find_all("p")

    symptoms_text = ""
    for p_tag in all_p_tags:
        # 获取每个段落的文字
        paragraph_text = p_tag.get_text(strip=True)
        # 跳过太短的段落（可能是空白或装饰文字）
        if len(paragraph_text) > 10:
            # 用中文句号（。）作为分隔，拼接段落
            symptoms_text = symptoms_text + paragraph_text + "。"

    # 限制症状文字长度，避免一个字段太长
    if len(symptoms_text) > 2000:
        # 只取前 2000 个字符
        symptoms_text = symptoms_text[:2000] + "...(后续内容省略)"

    print("  症状描述长度: " + str(len(symptoms_text)) + " 字符")

    # ---- 第三步：提取图片链接 ----
    all_img_tags = soup.find_all("img")

    image_urls = []
    for img_tag in all_img_tags:
        # .get("src") 获取图片的源地址
        img_src = img_tag.get("src", "")
        # .get("data-src") 有些网站用懒加载，真实地址在 data-src 属性中
        img_data_src = img_tag.get("data-src", "")

        # 优先使用 data-src，其次用 src
        real_src = ""
        if len(img_data_src) > 0:
            real_src = img_data_src
        else:
            real_src = img_src

        # 跳过空地址
        if len(real_src) == 0:
            continue

        # 跳过明显是图标、logo 的小图（通常文件名中有 "logo" 或 "icon"）
        if "logo" in real_src.lower():
            continue
        if "icon" in real_src.lower():
            continue

        # 拼成完整 URL
        if real_src.startswith("http"):
            full_img_url = real_src
        else:
            full_img_url = "https://jbk.familydoctor.com.cn" + real_src

        image_urls.append(full_img_url)

    print("  图片数量: " + str(len(image_urls)))

    # ---- 第四步：打包返回 ----
    result = {
        "name": disease_name,
        "symptoms": symptoms_text,
        "images": image_urls
    }

    return result

    4.3.4 用 URL 队列批量爬取详情页¶

    现在把 DFS 收集到的链接当作"排队号"，逐个处理：

    def crawl_using_queue(url_list, max_items):
    """
    用队列方式逐个处理 URL 列表。
    队列的特点：先进先出（FIFO），先放入的链接先处理。

    参数：
        url_list:  包含 {"name": 疾病名, "url": URL} 字典的列表
        max_items: 最多处理多少个（防止爬太多）

    返回：
        所有疾病详情的列表，每个元素是一个字典
    """
    # ---- 第一步：把 url_list 复制到队列中 ----
    # 用 .copy() 创建列表副本，保护原始数据
    # .copy() 是列表的方法，创建一个和原列表内容一样的新列表
    url_queue = []
    for item in url_list:
        url_queue.append(item)

    print("URL 队列初始化完成，共有 " + str(len(url_queue)) + " 个待爬链接")

    # ---- 第二步：逐个处理队列中的链接 ----
    all_details = []     # 存放所有爬取结果
    processed_count = 0  # 已处理的计数器

    # 循环条件：队列不为空 且 还没达到最大数量
    while len(url_queue) > 0 and processed_count < max_items:
        # 从队列头部取出一个元素
        # .pop(0) 移除并返回列表的第一个元素
        current_item = url_queue.pop(0)

        print("")
        print("-" * 40)
        print("队列剩余: " + str(len(url_queue)) + " 个 | 处理第 " + str(processed_count + 1) + " 个")

        # 爬取详情页
        detail_data = crawl_disease_detail(current_item["url"])

        if detail_data is not None:
            # 补充列表页的信息
            detail_data["list_name"] = current_item["name"]
            all_details.append(detail_data)
            processed_count = processed_count + 1

        # 每次请求后休息一下
        time.sleep(1)

    print("")
    print("=" * 60)
    print("队列处理完成！成功爬取 " + str(processed_count) + " 个疾病详情")
    print("=" * 60)

    return all_details

    #调用函数
    crawl_using_queue(url_queue, max_items=10)

    4.4 多线程基础 —— Daemon 线程、join 等待、线程池限制并发数¶

    4.4.1 为什么需要多线程 —— "开多个窗口下载"¶

    你肯定有过这样的体验：在电脑上同时下载多个文件。

    如果一次只下载一个文件，等它下完再下第二个，很慢对吧？但如果你同时开 5 个下载窗口，每个窗口下载不同的文件，总时间会缩短到原来的大约五分之一。

    爬虫也是一样。在 4.3 节中，我们的程序是一个接一个地爬取详情页——爬完第一个，再爬第二个。这叫单线程。

    多线程就是：同时开多个爬虫，每个爬虫负责爬取不同的页面。

    单线程模式（你之前的做法）：
时间线：|--爬疾病1--|--爬疾病2--|--爬疾病3--|--爬疾病4--|--爬疾病5--|
              ↑           ↑           ↑           ↑           ↑
          一个接一个，总共需要很长时间

多线程模式（5个线程同时工作）：
线程1：|--爬疾病1--|
线程2：|--爬疾病2--|
线程3：|--爬疾病3--|
线程4：|--爬疾病4--|
线程5：|--爬疾病5--|
       ↑ 同时进行，总时间缩短到原来的约 1/5

    4.4.2 线程是什么（用最简单的比喻）¶

    把线程想象成一个工人。

    • 单线程 = 你一个人干活。搬砖、砌墙、刷漆全是你一个人，一件一件来。
    • 多线程 = 你雇了 5 个工人。你（主线程）负责分配任务，工人 A 刷客厅的墙，工人 B 铺厨房的地砖，工人 C 装卫生间的马桶……大家同时干活。

    在 Python 中，用 import threading 来引入线程模块。

    4.4.3 创建第一个线程¶

    先写一个最简单的多线程例子，帮你建立感觉：

    import threading
import time


def worker(worker_name, sleep_time):
    """
    模拟一个工人执行任务。

    参数：
        worker_name: 工人名字（用于打印输出）
        sleep_time:  任务需要的时间（秒），用 sleep 模拟
    """
    print("[" + worker_name + "] 开始工作...")
    # time.sleep() 让程序暂停指定秒数
    # 这里用它来模拟"爬一个网页需要的时间"
    time.sleep(sleep_time)
    print("[" + worker_name + "] 工作完成！(耗时 " + str(sleep_time) + " 秒)")


# ========================================
# 单线程版本（作为对比基线）
# ========================================
print("===== 单线程版本 =====")
start_time = time.time()  # time.time() 返回当前时间戳（秒），用于计时

worker("工人A", 2)
worker("工人B", 2)
worker("工人C", 2)

# 计算总耗时
end_time = time.time()
# 两个时间戳相减，得到经过的秒数
elapsed = end_time - start_time
print("单线程总耗时: " + str(elapsed) + " 秒")
print("")

# ========================================
# 多线程版本
# ========================================
print("===== 多线程版本 =====")
start_time = time.time()

# 创建 3 个线程，每个线程执行 worker 函数，但参数不同
# threading.Thread() 创建一个线程对象
# 参数 target: 线程要执行的函数
# 参数 args: 传给 target 函数的参数，是一个元组
thread_a = threading.Thread(target=worker, args=("工人A", 2))
thread_b = threading.Thread(target=worker, args=("工人B", 2))
thread_c = threading.Thread(target=worker, args=("工人C", 2))

# 启动所有线程
# .start() 让线程开始运行（不是立即运行，而是告诉系统"可以跑了"）
thread_a.start()
thread_b.start()
thread_c.start()

# .join() 等待线程完成
# 如果不调用 join()，主线程会直接继续往下跑，不等工人干完活
thread_a.join()
thread_b.join()
thread_c.join()

end_time = time.time()
elapsed = end_time - start_time
print("多线程总耗时: " + str(elapsed) + " 秒")

    4.4.4 Daemon 线程 —— "老板走了我也走"¶

    有一种特殊的线程叫守护线程（Daemon Thread）。

    用比喻来理解： - 普通线程（默认）：老板（主线程）下班了，工人还在加班，必须等工人干完活才能关门。 - 守护线程：老板一下班，工人立刻收拾东西走人，不管活干没干完。

    import threading
import time


def long_task():
    """模拟一个需要很长时间的任务"""
    for i in range(10):
        print("守护线程工作中... 第 " + str(i + 1) + " 秒")
        time.sleep(1)


print("===== 普通线程（默认） =====")
normal_thread = threading.Thread(target=long_task)
normal_thread.start()

print("主线程说：我走了！")
# 但是程序不会立即退出，因为 normal_thread 还在运行
# （在 Python 中，默认会等所有非守护线程完成）

print("")
print("===== 守护线程 =====")
# daemon=True 将线程设为守护线程
daemon_thread = threading.Thread(target=long_task, daemon=True)
daemon_thread.start()
print("主线程说：我走了！")

    4.4.5 线程池 —— 控制并发数（重点）¶

    前面我们用 threading.Thread() 手动创建线程。但如果要爬 100 个页面，难道手动创建 100 个线程？

    而且还有一个严重问题：如果同时开 100 个线程访问同一个网站，服务器会被打垮（这相当于 DDoS 攻击，不仅不合规，还可能被网站封 IP）。

    解决方法是使用线程池（ThreadPoolExecutor）。

    线程池就像一个固定人数的施工队：

    ThreadPoolExecutor(max_workers=3)
     ↓
┌──────────────────────────────────┐
│            线程池                 │
│  ┌─────────┐ ┌─────────┐ ┌─────┐ │
│  │ 工人 A  │ │ 工人 B  │ │工人C│ │  ← 最多 3 个工人同时干活
│  └─────────┘ └─────────┘ └─────┘ │
│                                    │
│   排队等候的任务                    │
│   任务4  任务5  任务6  任务7 ...    │
│   ↑ 等工人空出来再分配              │
└──────────────────────────────────┘

    无论有多少个任务，同时干活的最多只有 max_workers 个。

    import time

# 导入线程池执行器
# concurrent.futures 是 Python 提供高级并发工具的模块
# ThreadPoolExecutor 是该模块中的线程池类
from concurrent.futures import ThreadPoolExecutor


def fetch_page(page_num):
    """
    模拟爬取一个页面（实际是 sleep 1.5 秒）。

    参数：
        page_num: 页面编号

    返回：
        一个字符串，说明爬取结果
    """
    print("  [线程开始] 正在爬取第 " + str(page_num) + " 页...")
    # 模拟网络请求耗时
    time.sleep(1)
    print("  [线程完成] 第 " + str(page_num) + " 页爬取完成")
    # 返回结果
    return "第" + str(page_num) + "页的内容"


# ========================================
# 单线程版本（对比对照组）
# ========================================
print("===== 单线程：逐个爬取 10 页 =====")
start_time = time.time()

for page in range(1, 11):
    result = fetch_page(page)

end_time = time.time()
print("单线程总耗时: " + str(round(end_time - start_time, 1)) + " 秒")
print("")

# ========================================
# 多线程版本（线程池，3 个工人）
# ========================================
print("===== 多线程（线程池）：3 个工人同时爬取 10 页 =====")
start_time = time.time()

# 创建一个线程池，最多同时运行 3 个线程
# ThreadPoolExecutor() 创建一个线程池对象
# 参数 max_workers: 最大并发线程数（即最多几个工人同时干活）
executor = ThreadPoolExecutor(max_workers=3)

# 提交所有任务
# executor.submit() 提交一个任务到线程池
# 参数1：要执行的函数
# 参数2...：传给函数的参数
# submit() 返回一个 Future 对象，代表"将来会完成的结果"
futures = []
for page in range(1, 11):
    future = executor.submit(fetch_page, page)
    futures.append(future)

# 等待所有任务完成，收集结果
# future.result() 获取任务的返回值
# 如果任务还没完成，result() 会阻塞等待直到完成
all_results = []
for future in futures:
    result = future.result()
    all_results.append(result)

end_time = time.time()
print("")
print("多线程总耗时: " + str(round(end_time - start_time, 1)) + " 秒")
print("收集结果数量: " + str(len(all_results)))

    4.4.6 多线程调试技巧 —— 打印线程名¶

    多线程程序最难搞的地方是调试——因为多个线程同时运行，输出的顺序是乱的，你没法按照代码顺序来理解执行过程。

    最好的调试方法是在每次打印时带上线程名称：

    import threading
import time
from concurrent.futures import ThreadPoolExecutor


def fetch_with_debug(page_num):
    """
    爬取页面，并打印详细的线程调试信息。
    """
    # threading.current_thread().name 获取当前线程的名称
    # 线程池中的线程名称形如 "ThreadPoolExecutor-0_0"
    thread_name = threading.current_thread().name

    print("[" + thread_name + "] 🔵 开始爬取第 " + str(page_num) + " 页")
    time.sleep(1)
    print("[" + thread_name + "] 🟢 第 " + str(page_num) + " 页爬取完成")

    return "结果" + str(page_num)


print("===== 多线程调试演示（注意观察线程名的交替） =====")
print("")

# 线程池最多 3 个工人
executor = ThreadPoolExecutor(max_workers=3)

# 提交 9 个任务
futures = []
for i in range(1, 10):
    future = executor.submit(fetch_with_debug, i)
    futures.append(future)

# 等待完成
for future in futures:
    future.result()

print("")
print("===== 调试技巧总结 =====")
print("1. 观察上面的输出，线程名是否在交替出现？")
print("2. 如果某个线程名一直出现，说明它可能被阻塞了")

    4.4.7 线程安全 —— 使用 queue.Queue（重要）¶

    多线程有一个经典陷阱：多个线程同时写同一个列表，可能导致数据错乱。

    用比喻理解： - 你和朋友同时往一个记事本上写字。你写"今天天"，朋友同时写"气真好"，最后纸上可能是"今天天气天真好"——数据乱了。

    Python 的 queue.Queue 是线程安全的队列。它自带一把"锁"，任何时候只允许一个线程往里放东西或取东西。

    import threading
import time
import queue

# ========================================
# 不安全的写法（演示用，不要在生产代码中使用）
# ========================================

unsafe_list = []


def unsafe_add(value):
    """直接追加到普通列表 —— 多线程下不安全"""
    unsafe_list.append(value)


# ========================================
# 安全的写法：使用 queue.Queue
# ========================================

# queue.Queue() 创建一个线程安全的队列对象
# maxsize=0 表示不限制队列大小
safe_queue = queue.Queue(maxsize=0)

# Lock 是一把"互斥锁"，确保同一时刻只有一个线程进入被保护的代码段
print_lock = threading.Lock()


def safe_add(value):
    """使用线程安全队列"""
    # .put() 是队列的方法，将数据放入队列
    # 这是线程安全的，多个线程同时调用也不会出错
    safe_queue.put(value)

    # 使用锁来保护打印输出
    # print 本身不是线程安全的，多个线程同时 print 可能乱掉
    # print_lock.acquire() 获取锁——拿到锁的人才能打印
    print_lock.acquire()
    print("[" + threading.current_thread().name + "] 存入: " + str(value))
    # print_lock.release() 释放锁——让其他线程可以使用打印机
    print_lock.release()


print("===== 线程安全队列演示 =====")
print("")

# 创建 5 个线程同时往队列里放数据
threads = []
for i in range(5):
    # 创建线程，都执行 safe_add 函数
    t = threading.Thread(target=safe_add, args=(i,))
    threads.append(t)
    t.start()

# 等待所有线程完成
for t in threads:
    t.join()

# 从队列中取出所有数据
print("")
print("从安全队列中取出数据：")
# .empty() 检查队列是否为空，返回 True 或 False
while not safe_queue.empty():
    # .get() 从队列中取出一个数据（先进先出）
    item = safe_queue.get()
    print("  取出: " + str(item))

    4.5.1 下载一张图片（基础版）¶

    下载图片的原理和下载网页一模一样——用 requests.get() 发送请求，但这次我们不是读取文字（.text），而是读取二进制数据（.content），然后写入文件。

    import requests
import os
import time

# 请求头
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
}


def download_single_image(image_url, save_folder, file_name):
    """
    下载一张图片并保存到本地文件夹。

    参数：
        image_url:   图片的完整 URL
        save_folder: 保存到哪个文件夹（如 "images/"）
        file_name:   保存的文件名（如 "pic001.jpg"）

    返回：
        成功返回完整的保存路径，失败返回 None
    """
    # ---- 第一步：确保文件夹存在 ----
    # os.path.exists() 检查路径是否存在（文件或文件夹都行）
    # 返回 True 表示存在，False 表示不存在
    if not os.path.exists(save_folder):
        # os.makedirs() 创建文件夹（包含所有中间文件夹）
        # 参数1：要创建的文件夹路径
        os.makedirs(save_folder)
        print("创建文件夹: " + save_folder)

    # ---- 第二步：拼接完整的保存路径 ----
    # os.path.join() 把文件夹路径和文件名拼在一起
    # 自动处理不同操作系统的路径分隔符（Windows 用 \，Mac/Linux 用 /）
    save_path = os.path.join(save_folder, file_name)

    # ---- 第三步：发送请求获取图片数据 ----
    try:
        # 请求图片 URL
        response = requests.get(image_url, headers=headers, timeout=30)

        # 检查状态码
        if response.status_code != 200:
            print("  下载失败，状态码: " + str(response.status_code))
            return None

        # ---- 第四步：写入文件 ----
        # open() 打开文件
        # 参数1：文件路径
        # 参数2："wb" —— w 表示写入（write），b 表示二进制模式（binary）
        #        图片是二进制数据，必须用 "wb" 模式
        # 注意：一个 with 只做一件事（打开文件+写入），后面关掉再开
        file_handle = open(save_path, "wb")
        # response.content 是图片的二进制数据（和 response.text 不同）
        # .write() 把二进制数据写入文件
        file_handle.write(response.content)
        file_handle.close()

        # 获取文件大小
        # os.path.getsize() 返回文件大小（字节）
        file_size = os.path.getsize(save_path)
        print("  图片已保存: " + file_name + " (" + str(file_size) + " 字节)")

        return save_path

    except Exception as e:
        # 如果出现任何错误，打印错误信息
        print("  下载出错: " + str(e))
        return None

    4.5.2 处理重名覆盖 —— 用 MD5 命名（重要）¶

    下载大量图片时，不同页面的图片可能重名。比如两个疾病详情页都有 banner.jpg，后下载的会覆盖先下载的。

    解决方法：用文件的 MD5 哈希值作为文件名。

    MD5 是什么？你可以把它理解成文件的"指纹"。给定任意一段数据，MD5 算法会计算出 32 个字符的"指纹"。相同的数据 → 相同指纹；不同的数据 → 不同指纹。

    用 MD5 给图片命名有两个好处： 1. 不会重名：不同图片的 MD5 值几乎不可能相同 2. 自动去重：同一张图片（比如同一个 logo）不会被重复下载，因为 MD5 一样，文件已存在就跳过

    import hashlib


def calculate_md5(data_bytes):
    """
    计算一段二进制数据的 MD5 值。

    参数：
        data_bytes: 二进制数据（bytes 类型）

    返回：
        32 个字符的 MD5 字符串，例如 "d41d8cd98f00b204e9800998ecf8427e"
    """
    # hashlib.md5() 创建一个 MD5 计算器对象
    # 参数：要计算的数据（必须是 bytes 类型）
    md5_calculator = hashlib.md5()
    # .update() 把数据喂给计算器
    md5_calculator.update(data_bytes)
    # .hexdigest() 输出最终结果——32 个十六进制字符的字符串
    md5_result = md5_calculator.hexdigest()
    return md5_result


def download_image_with_md5(image_url, save_folder):
    """
    下载图片，用 MD5 值命名，防止重名和重复下载。

    参数：
        image_url:   图片的完整 URL
        save_folder: 保存到哪个文件夹

    返回：
        成功返回保存路径，失败或已存在返回 None
    """
    # ---- 第一步：确保文件夹存在 ----
    if not os.path.exists(save_folder):
        os.makedirs(save_folder)

    # ---- 第二步：下载图片数据 ----
    try:
        response = requests.get(image_url, headers=headers, timeout=30)
        if response.status_code != 200:
            return None

        # 获取二进制图片数据
        image_data = response.content

        # ---- 第三步：计算 MD5 ----
        md5_value = calculate_md5(image_data)

        # ---- 第四步：判断文件扩展名 ----
        # 扩展名就是文件名的后缀，如 .jpg .png .gif
        # 从 URL 中提取扩展名
        extension = ".jpg"  # 默认用 jpg
        # 检查 URL 中是否包含常见的图片扩展名
        if ".png" in image_url.lower():
            extension = ".png"
        elif ".gif" in image_url.lower():
            extension = ".gif"
        elif ".webp" in image_url.lower():
            extension = ".webp"

        # 拼出完整的文件名：MD5值 + 扩展名
        file_name = md5_value + extension

        # ---- 第五步：断点续传 —— 检查文件是否已存在 ----
        save_path = os.path.join(save_folder, file_name)
        if os.path.exists(save_path):
            # 文件已经存在，不重复下载
            print("  [跳过] 文件已存在: " + file_name[:16] + "..." + extension)
            return save_path

        # ---- 第六步：保存文件 ----
        file_handle = open(save_path, "wb")
        file_handle.write(image_data)
        file_handle.close()

        file_size = os.path.getsize(save_path)
        print("  [保存] " + file_name[:16] + "..." + extension + " (" + str(file_size) + " 字节)")

        return save_path

    except Exception as e:
        print("  下载出错: " + str(e))
        return None

        save_folder: 保存到哪个文件夹

    返回：
        (成功数量, 总耗时秒数)
    """
    print("===== 单线程下载开始 =====")
    start_time = time.time()

    success_count = 0
    for i in range(len(image_urls)):
        url = image_urls[i]
        print("(" + str(i + 1) + "/" + str(len(image_urls)) + ") ", end="")
        result = download_image_with_md5(url, save_folder)
        if result is not None:
            success_count = success_count + 1

    end_time = time.time()
    elapsed = end_time - start_time
    print("单线程完成: " + str(success_count) + "/" + str(len(image_urls)) + " 张, 耗时 " + str(round(elapsed, 1)) + " 秒")
    return success_count, elapsed


def download_images_multi_thread(image_urls, save_folder, max_workers):
    """
    多线程（线程池）下载图片列表中的所有图片。

    参数：
        image_urls:  图片 URL 的列表
        save_folder: 保存到哪个文件夹
        max_workers: 最大并发线程数

    返回：
        (成功数量, 总耗时秒数)
    """
    print("===== 多线程下载开始（最多 " + str(max_workers) + " 个线程） =====")
    start_time = time.time()

    # 创建线程池
    executor = ThreadPoolExecutor(max_workers=max_workers)

    # 提交所有下载任务
    futures = []
    for url in image_urls:
        # executor.submit() 提交任务，返回 Future 对象
        future = executor.submit(download_image_with_md5, url, save_folder)
        futures.append(future)

    # 等待所有任务完成
    success_count = 0
    for future in futures:
        result = future.result()
        if result is not None:
            success_count = success_count + 1

    end_time = time.time()
    elapsed = end_time - start_time
    print("多线程完成: " + str(success_count) + "/" + str(len(image_urls)) + " 张, 耗时 " + str(round(elapsed, 1)) + " 秒")
    return success_count, elapsed

def safe_print(message):
    """
    线程安全的打印函数。
    使用锁确保同一时刻只有一个线程在打印。

    参数：
        message: 要打印的字符串
    """
    # 获取打印锁
    print_lock.acquire()
    # 打印
    print(message)
    # 释放打印锁
    print_lock.release()


def calculate_md5(data_bytes):
    """
    计算二进制数据的 MD5 哈希值，用于图片文件命名。

    参数：
        data_bytes: 二进制数据

    返回：
        32 个字符的 MD5 字符串
    """
    # 创建 MD5 计算器
    md5_calc = hashlib.md5()
    # 喂入数据
    md5_calc.update(data_bytes)
    # 输出结果
    return md5_calc.hexdigest()

def crawl_list_page_dfs(category_id, page_num, max_depth):
    """
    DFS 方式爬取某个科室下所有列表页，收集疾病详情页链接。

    参数：
        category_id: 科室 ID（1=内科, 2=外科, ...）
        page_num:    当前页码（从1开始）
        max_depth:   最大递归深度
    """
    # ---- 终止条件 ----
    if page_num > max_depth:
        return
    if page_num > MAX_PAGES_PER_DEPT:
        return

    # ---- 构造 URL ----
    url = ("https://jbk.familydoctor.com.cn/category_"
           + str(category_id) + "_0_" + str(page_num) + ".html")

    safe_print("[DFS] 正在爬取列表页: " + url)

    # ---- 发送请求 ----
    response = requests.get(url, headers=headers, timeout=15)
    if response.status_code != 200:
        safe_print("[DFS] 页面不存在（状态码=" + str(response.status_code) + "），停止递归")
        return

    if len(response.text) < 1000:
        safe_print("[DFS] 页面过短，可能被拦截，停止递归")
        return

    # ---- 解析 HTML ----
    soup = BeautifulSoup(response.text, "html.parser")

    # ---- 第一步：找到所有 a 标签 ----
    all_a_tags = soup.find_all("a")

    # ---- 第二步：筛选疾病详情链接 ----
    page_disease_count = 0
    for a_tag in all_a_tags:
        href_value = a_tag.get("href", "")
        link_text = a_tag.get_text(strip=True)

        # 判断是否是疾病详情链接：/info 开头
        if "/info" in href_value and len(link_text) > 0:
            # 拼接完整 URL
            if href_value.startswith("http"):
                full_url = href_value
            else:
                full_url = "https://jbk.familydoctor.com.cn" + href_value

            # 存入全局列表
            disease_info = {"name": link_text, "url": full_url}
            collected_disease_links.append(disease_info)
            page_disease_count = page_disease_count + 1

    safe_print("[DFS] 本页收集到 " + str(page_disease_count)
               + " 个链接，累计 " + str(len(collected_disease_links)) + " 个")

    # ---- 礼貌等待 ----
    time.sleep(REQUEST_DELAY)

    # ---- 递归：爬下一页 ----
    crawl_list_page_dfs(category_id, page_num + 1, max_depth)


def collect_all_disease_links(department_ids):
    """
    对所有科室执行 DFS，收集所有疾病详情页链接并去重。

    参数：
        department_ids: 科室 ID 列表

    返回：
        去重后的疾病链接列表
    """
    global collected_disease_links
    collected_disease_links = []

    safe_print("=" * 60)
    safe_print("阶段一：DFS 收集疾病链接")
    safe_print("=" * 60)

    # 对每个科室执行 DFS
    for dept_id in department_ids:
        safe_print("")
        safe_print("开始爬取科室 " + str(dept_id) + " ...")
        crawl_list_page_dfs(dept_id, 1, MAX_PAGES_PER_DEPT)

    # ---- 去重 ----
    # 有些疾病可能在多个分类页重复出现（比如内科和儿科都有"感冒"）
    # 用 URL 作为去重的依据
    safe_print("")
    safe_print("去重前: " + str(len(collected_disease_links)) + " 个链接")

    # 创建一个集合（set），自动去除重复元素
    seen_urls = set()
    unique_links = []
    for link in collected_disease_links:
        url = link["url"]
        if url not in seen_urls:
            seen_urls.add(url)
            unique_links.append(link)

    safe_print("去重后: " + str(len(unique_links)) + " 个链接")

    return unique_links

def crawl_disease_detail(disease_info):
    """
    爬取一个疾病详情页，提取名称、症状、图片。

    参数：
        disease_info: 字典 {"name": 疾病名, "url": 详情页URL}

    返回：
        字典，包含 "name", "symptoms", "image_urls", "saved_images"
        失败返回 None
    """
    detail_url = disease_info["url"]

    safe_print("  [详情] 正在爬取: " + disease_info["name"])

    # ---- 发送请求 ----
    response = requests.get(detail_url, headers=headers, timeout=15)
    if response.status_code != 200:
        safe_print("  [详情] 请求失败: " + str(response.status_code))
        return None

    # ---- 解析 HTML ----
    soup = BeautifulSoup(response.text, "html.parser")

    # ---- 第一步：提取疾病名称 ----
    h1_tag = soup.find("h1")
    if h1_tag is not None:
        disease_name = h1_tag.get_text(strip=True)
    else:
        title_tag = soup.find("title")
        if title_tag is not None:
            disease_name = title_tag.get_text(strip=True)
        else:
            disease_name = disease_info["name"]

    # ---- 第二步：提取症状描述 ----
    all_p_tags = soup.find_all("p")
    symptoms_text = ""
    for p_tag in all_p_tags:
        paragraph_text = p_tag.get_text(strip=True)
        if len(paragraph_text) > 10:
            symptoms_text = symptoms_text + paragraph_text + "。"

    # 限制长度
    if len(symptoms_text) > 2000:
        symptoms_text = symptoms_text[:2000] + "...(后续内容省略)"

    # ---- 第三步：提取图片链接 ----
    all_img_tags = soup.find_all("img")
    image_urls = []
    for img_tag in all_img_tags:
        img_src = img_tag.get("src", "")
        img_data_src = img_tag.get("data-src", "")

        # 优先用 data-src（懒加载的情况）
        real_src = ""
        if len(img_data_src) > 0:
            real_src = img_data_src
        else:
            real_src = img_src

        if len(real_src) == 0:
            continue

        # 跳过 logo 和 icon
        if "logo" in real_src.lower():
            continue
        if "icon" in real_src.lower():
            continue

        # 拼接完整 URL
        if real_src.startswith("http"):
            full_img_url = real_src
        else:
            full_img_url = "https://jbk.familydoctor.com.cn" + real_src

        image_urls.append(full_img_url)

    # ---- 第四步：下载图片（多线程在详情爬取阶段完成） ----
    saved_image_names = []
    for img_url in image_urls:
        saved_name = download_and_save_image(img_url, IMAGES_FOLDER)
        if saved_name is not None:
            saved_image_names.append(saved_name)

    # ---- 第五步：打包结果 ----
    result = {
        "name": disease_name,
        "url": detail_url,
        "symptoms": symptoms_text,
        "image_count": len(image_urls),
        "saved_images": saved_image_names,
        "source": disease_info.get("list_name", "")
    }

    safe_print("  [详情] 完成: " + disease_name + " (图片 " + str(len(saved_image_names)) + " 张)")

    return result

def download_and_save_image(image_url, save_folder):
    """
    下载图片，用 MD5 命名，支持断点续传（已存在则跳过）。

    参数：
        image_url:   图片 URL
        save_folder: 保存文件夹

    返回：
        成功返回文件名（含扩展名），失败返回 None
    """
    # 确保文件夹存在
    ensure_folder(save_folder)

    try:
        # 下载图片
        response = requests.get(image_url, headers=headers, timeout=30)
        if response.status_code != 200:
            return None

        image_data = response.content

        # 计算 MD5
        md5_value = calculate_md5(image_data)

        # 判断扩展名
        extension = ".jpg"
        if ".png" in image_url.lower():
            extension = ".png"
        elif ".gif" in image_url.lower():
            extension = ".gif"
        elif ".webp" in image_url.lower():
            extension = ".webp"

        # 拼文件名
        file_name = md5_value + extension
        save_path = os.path.join(save_folder, file_name)

        # 断点续传：已存在则跳过
        if os.path.exists(save_path):
            return file_name

        # 保存
        file_handle = open(save_path, "wb")
        file_handle.write(image_data)
        file_handle.close()

        return file_name

    except Exception:
        return None

def crawl_all_details_single_thread(disease_links):
    """
    单线程版本：逐个爬取疾病详情。

    参数：
        disease_links: 疾病链接列表

    返回：
        (结果列表, 耗时秒数)

    safe_print("单线程模式：逐个爬取疾病详情")
    safe_print("=" * 60)

    start_time = time.time()
    all_results = []

    for i in range(len(disease_links)):
        link = disease_links[i]
        safe_print("(" + str(i + 1) + "/" + str(len(disease_links)) + ")")
        result = crawl_disease_detail(link)
        if result is not None:
            all_results.append(result)
        time.sleep(REQUEST_DELAY)

    end_time = time.time()
    elapsed = end_time - start_time
    safe_print("单线程完成: " + str(len(all_results)) + " 个疾病, 耗时 "
               + str(round(elapsed, 1)) + " 秒")
    return all_results, elapsed


def crawl_all_details_multi_thread(disease_links):
    """
    多线程版本：用线程池并发爬取疾病详情。

    参数：
        disease_links: 疾病链接列表

    返回：
        (结果列表, 耗时秒数)
    """
    safe_print("")
    safe_print("=" * 60)
    safe_print("多线程模式：并发爬取疾病详情（最多 " + str(MAX_WORKERS) + " 个线程）")
    safe_print("=" * 60)

    start_time = time.time()

    # 创建线程池
    executor = ThreadPoolExecutor(max_workers=MAX_WORKERS)

    # 提交所有任务
    future_to_link = {}
    for link in disease_links:
        future = executor.submit(crawl_disease_detail, link)
        future_to_link[future] = link

    # 收集结果
    all_results = []
    completed = 0
    total = len(future_to_link)

    # as_completed() 返回一个迭代器，每当有一个任务完成就 yield 它的 future
    # 这比先提交再逐个 .result() 更高效
    for future in as_completed(future_to_link):
        completed = completed + 1
        safe_print("进度: " + str(completed) + "/" + str(total))
        try:
            result = future.result()
            if result is not None:
                all_results.append(result)
        except Exception as e:
            safe_print("任务出错: " + str(e))

    end_time = time.time()
    elapsed = end_time - start_time
    safe_print("多线程完成: " + str(len(all_results)) + " 个疾病, 耗时 "
               + str(round(elapsed, 1)) + " 秒")
    return all_results, elapsed

def save_to_json(data, file_path):
    """
    将爬取结果保存为 JSON 文件。

    参数：
        data:      要保存的数据（列表或字典）
        file_path: JSON 文件的保存路径
    """
    ensure_folder(OUTPUT_FOLDER)

    # open() 打开文件
    # 参数"w"：写入文本模式
    # encoding="utf-8"：使用 UTF-8 编码（支持中文）
    file_handle = open(file_path, "w", encoding="utf-8")

    # json.dump() 将 Python 数据写入 JSON 格式
    # 参数1：要写入的数据
    # 参数2：打开的文件对象
    # ensure_ascii=False：不要对中文进行 Unicode 转义（保持中文可读）
    # indent=2：缩进 2 个空格，让 JSON 文件美观易读
    json.dump(data, file_handle, ensure_ascii=False, indent=2)

    file_handle.close()

    safe_print("JSON 文件已保存: " + file_path)

    🔑 关键概念小结¶

    1. 递归不是魔法——就是函数调用自己，每次处理比上一次小一点的问题
    2. 多线程加速的本质——利用等待网络的时间同时做别的事，不是让 CPU 算得更快
    3. 线程安全不是可选项——多个线程同时写一个变量肯定出错，Queue 和 Lock 是必修课
    4. 爬虫的礼貌——sleep() 间隔 + max_workers 限制 = 不给服务器添麻烦
