    Python爬虫实战教程 — 医疗公开数据¶

    欢迎！这是一套为零基础大专学生编写的 Python 爬虫实战教程，共 9 个项目，涵盖从基础网页采集、框架与浏览器自动化，到医疗大数据 API 和 AI 结构化抽取的完整学习路线。

    课程特色¶

    • 全程基于真实公开的医疗健康网站
    • 从 requests 到 Scrapy、Selenium、医疗数据 API 和本地 AI，循序渐进
    • 每行代码都有详细注释，零基础也能看懂
    • 配合作业练习，边学边练
    • 只使用公开数据，强调限速、隐私、证据核验和人工复核

    项目列表¶

    项目 标题 核心技术
    项目1 爬取国家中医药管理局时政要闻数据 requests + BeautifulSoup
    项目2 爬取医疗健康资讯网站数据 requests + 分页爬取
    项目3 XPath爬取医学百科药品数据 lxml + XPath
    项目4 爬取医学百科网站数据 requests + 多页面爬取
    项目5 Scrapy入门指导书 Scrapy 框架
    项目6 Selenium动态爬虫实战 Selenium + ChromeDriver
    项目7 ClinicalTrials.gov 临床试验大数据保姆级实战 JSON API + 游标分页 + 断点续爬
    项目8 PubMed 医学文献大数据保姆级实战 E-utilities + JSON/XML + 批量采集
    项目9 AI 医学文献智能爬虫保姆级实战 PubMed + Ollama + 结构化抽取 + 结果校验

    学习路线¶

    阶段 项目 能力目标
    基础采集 项目1-4 请求网页、解析 HTML、翻页与多页面采集
    工程工具 项目5-6 使用 Scrapy 组织项目，处理动态网页
    医疗大数据 项目7-8 调用官方数据 API，处理 JSON/XML 和批量任务
    AI 综合 项目9 在可靠爬虫后增加 AI，并校验、追踪和复核结果

    环境要求¶

    • Python 3.8 或更高版本
    • VS Code（编程环境）
    • 需要安装的库在各项目中单独说明
    • 项目9需要安装 Ollama；电脑性能不足时可由老师提供统一服务

    使用方法¶

    从左侧导航栏选择项目，按顺序学习即可。项目7和项目8是项目9的数据与工程基础，不建议直接跳到 AI 项目。

    项目7-9每章都拆成4个可单独运行的小程序。请完成当前步骤的“成功检查点”后再进入下一步，最后再运行完整工程版。
